# 真实墙钟自然入口适配器：本地验收协议

冻结前登记，2026-10-25。此批独立于完整回合批、自然 Agent 准备包及旧 360 次队列。

## 范围与固定输入

只运行本地 SDK MockTransport 和真实 ASGI 模拟器。禁用网络及 provider 配置加载；不调用真实模型、不启动训练、不派发拟议 14 槽。使用原 `b1eb0270` 任务及冻结初态、时间线和原检查树；校验旧完整回合 run-02 的来源与输入哈希。

运行器不预置计划、预载公开 board 或选择 skill；独立本地 fixture 产生固定模型响应，因此仅验收自然入口的接线和生命周期，不验证模型自主选择能力。检查器根元数据添加私有 canary，不修改原检查叶子；评分只在 worker 退出并封存后，由独立新进程进行。

正常任务窗保持原 500 秒，原每计划 2,000 API、16 修复、16 轮以及 600 steps/1,800 recursion 不增加。`task_deadline` 使用明确派生的 1 秒真实墙钟边界探针，不声称执行了完整 500 秒压力测试。时间线随真实 `time.monotonic` 推进，启用 World timer；不用虚拟时钟。

## 固定顺序与预期

共 12 个 worker，预期 10 个独立 scorer。每个 worker 均恢复同一初态，新进程退出并确认回收后才进入评分或下一个预定本地探针。

| 场景 | 模型 fixture 行为及预期 |
| --- | --- |
| skill_success | list_drones → run_harness/simple_chain → 结束；原 checker 通过 |
| raw_success | list_drones → 起飞 14 → 转向 353 → 悬停 → 结束；原 checker 通过 |
| http_error | 真实起飞后第三 HTTP 返回 500；停止，原 checker 不通过 |
| request_timeout | 第三请求真实阻塞超过 0.1 秒请求时限；迟到响应只归私有诊断，不转向 |
| task_deadline | 第三请求等待超过 1 秒任务截止；冻结结果后迟到响应不能驱动动作 |
| cancel | 第三请求等待期间请求取消；记录 requested/effective 时刻，冻结后不执行转向 |
| http_limit | 第三请求准入时达到 2 次 HTTP 上限；禁止第三次实际 dispatch |
| usage_missing | — |
| usage_stop | 两次响应共 52 个合成 token；禁止第三次实际 dispatch |
| hung_drain | 第三请求永久阻塞，0.1 秒请求超时、0.15 秒排空失败；父进程强杀并回收，拒绝评分 |
| watchdog_hang | 第三请求永久阻塞；请求时限 30 秒，父本地 4 秒熔断先强杀并回收，拒绝评分 |
| post_kill_B | 与 skill_success 相同；核对初态、首次模型完整输入（仅命令 ID 归一）、动作和检查结果 |

必须从独立传输日志确认两个强杀探针已有真实起飞和第三个在途请求，不能把导入/初始化失败当作成功测试。预定强杀后的 B 只是本地隔离探针，不授权在线故障后继续队列。非预期基础设施失败立即停止并保留本轮，修复使用新目录，不覆盖失败。

## 请求、排空与评分边界

本批只支持同步、非流式 JSON。每请求必须显式设置输出上限，本地默认 max HTTP=8、max total tokens=1,000、max output tokens=256、单请求 5 秒、排空 0.5 秒；各场景覆盖上述特定值。正常父 watchdog=15 秒、scorer watchdog=15 秒，均为本地测试熔断，并非未来线上预算。fixture 每个正常响应 usage=17 输入+9 输出，属于合成计量。

准入在实际 delegate 前再次检查任务截止、请求截止、取消和关闭。完整响应缓存后才交给 SDK；阻塞传输在 daemon I/O 线程运行，主线程截止返回。迟到正文及其 usage 在有界排空后只落私有诊断；Agent 归档与模拟器状态必须在排空期间保持不变。线程未结束则不产生可评分的完成记录，由父 kill+wait；仅存在 score snapshot 不足以授权评分。

HTTP 次数是发起层硬限额；未知 usage 显式标记并停止；未实际发出的请求不可伪造零 token。HTTP 500 的响应可进入 SDK 错误归档，但不得触发工具动作。预定模型异常的七个完成 worker 应有 valid 但 partial 的模型交互归档。

取消请求即时关闭后续准入；实际冻结需获取 World 锁，已经进入锁内的动作可能先完成。记录取消请求与生效两时刻，不承诺信号时刻撤销动作。此批集成取消/截止发生在模型等待期间；模拟器原子动作跨截止回滚另引用既有专项测试，不能扩大为所有竞态已验收。

策略端只允许现有公开读取、无人机命令与碰撞查询；拒绝管理权限及地图/会话写入。要求独占无 lifespan 的 ASGI 环境、时间线只含目标/环境变化，并核对障碍几何初尾一致。隐藏检查、canary 和评分快照仅存私有/评估目录。当前动作计数包含非 GET 的请求，未来含碰撞 POST 的任务须另区分查询与物理命令成本。

## 验收与结论限制

父进程记录实际 PID、退出/回收时序；完成 worker 的记录及正文先验哈希，再允许 scorer。评分后复核 worker 封存，下一回合后复核评分封存。独立 oracle 关联传输请求/响应 hash、controller attempts、实际 I/O 归档和真实动作，检查迟到正文没有回流模型。检查完整输入及全部 policy 文件中无私有 canary/检查树泄漏。

专项测试覆盖准入、重试/异常/取消、排空、父子进程退出顺序、评分前完整性校验及静态写入契约。报告分别给出代码测试、完整本地链路检查、独立审计的分母；成功探针不汇总成 Benchmark 成功率。

现有自然准备包保持 online_ready=false，线上授权数和新增在线预算均为 0。
