# 搜索成本与输入冗余：本地改版验收协议

日期：2026-11-03。用户要求优先收敛搜索成本与输入冗余，保留已验证的隔离、归档及恢复正确性。本轮仅做实现、已知开发场景的本地验证和历史请求只读分析；真实 provider 调用数为 0，正式 Teacher 和第五项均不启动。

## 固定改动范围

1. `compact_tools_v1`：system prompt 的 AVAILABLE TOOLS 部分仅保留工具名称，完整描述继续由原生 tools schema 提供。原任务、所有操作/安全规则、schema、工具参数、历史回执、reasoning、证据附注及恢复投影不删改；不自动规范化模型错误参数。`full_v1` 保持默认旧布局。
2. `search_progress_v8` 候选：继承 v7 的原语法、观察权限、静态障碍共享、已观察目标跟进、预算和失败恢复。只由公开任务进度与新观察目标驱动新增完成确认/停滞交回；不查询隐藏 checker 或私有状态，不将交回解释为完成或不可解。
3. 显式本地 profile v3 选择两个独立维度；旧 v1/v2、旧线上协议和应用默认不自动切换。所有配置继续 fresh worker → 完整归档/排空 → 独立 scorer。

搜索候选保留 16 轮、每计划 2,000 API、16 次 repair 及原外层预算。新的公开 reach 证据只触发一次进度核查，只有可用同会话进度严格超过 95% 才可完成。已有正进度后，在两个完整的既有 10 move 观察窗口内都无进度增长，且没有新验证固定目标 ID/待执行跟进时，允许以 `needs_replan/search_progress_stalled` 交回模型。进度增长或新验证固定目标 ID 重置观察窗口；新 ID 即使暂不可跟进也保守重置，已有待执行跟进则另按主体、状态、几何及共享守卫判断。首次正进度前保留原探索窗口。unknown/partial/作用域失效等既有退出规则优先，不由停滞规则覆盖。

这是受资源约束的开发候选；未见目标可能在后面才被发现，提前交回有损失探索覆盖的风险。不得因节省动作就宣称同等成功率或最优停止策略。阈值在本地场景运行前固定，不依据本轮结果逐题调整。

## 验收分层

| 层 | 固定范围 | 可支持的结论 |
| --- | --- | --- |
| 搜索实际 ASGI 对照 | 原 7 题（3 搜索、2 短链、2 语法负例）及本次 `fdd21809`；v7/v8 同初态、同预算，脚本显式提交子程序 | 动作/API/进度/终态是否变化及既有成功是否丢失；不能算自然选技能或模型 token 收益 |
| 完整 SDK/Agent 运行链 | 7 条件 × 2 配置=14 槽：正常短链技能、导航原工具、fdd 搜索技能退出、unknown 原工具、unknown 子程序、partial 剩余恢复正例及省略恢复负例 | 本地接线、独立评分、实际 wire 字节和恢复约束；脚本决策与 usage 不记真实模型成绩 |
| 历史真实 wire 反事实分析 | 前批 56 个实际派发请求，两臂全部保留；2 个预算拒绝请求另列 | — |
| 回归与保护 | — | 已知实现边界未退化；不能保证未测场景正确或自然模型行为保持 |

搜索初步对照如丢失任一原成功正例，则拒收该停滞候选并保留结果，不通过删题、换阈值或追加预算制造改善。完整链必须保留计划/启动/评分/未运行分母及负例；正常返回不等于任务成功。失败时保留原尝试，修复接线缺陷后另建目录，不覆盖原件。

输入反事实分析只在可精确匹配原生 schema 描述副本的目录段替换；其余 system 正文、全部非 system 消息及原生 tools schema 均需逐值相同。分别记录原实际 body 字节与同序列化规范下的新旧字节，不能把字符/字节下降比例换算为 DeepSeek token 节省比例。原始请求及响应不可改写，不复制大段 reasoning 到报告。

## 交付与解释

新源码、选择配置、固定脚本、原始本地回合、反事实审计、代码测试与独立报告一起交付。不能把纯状态/脚本通过写成新增真实模型成功率；“保留已有能力”仅限本轮对照及测试覆盖。整合版原真实结果仍为两臂 3/4 条件成功、I 总 token +11.6%，不会被本地压缩结果追溯更改。

本轮不触发新付费批次。后续若需测真实 token、参数错误率、自然恢复和成功率，应在候选确定后另行冻结同期协议与额度。
