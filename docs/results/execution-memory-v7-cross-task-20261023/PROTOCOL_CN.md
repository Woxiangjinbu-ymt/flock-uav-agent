# v7 跨任务离线忠实性审计协议

冻结日期：2026-10-23。运行前写入本协议与 [cohort.json](cohort.json)，主样本严格为原 screen.json 中所有 14 个 `all_route_points_locally_legal_at_nominal_altitude=true` 任务，不根据本次投影或结果删选。

## 输入与隔离

- 主分析使用每题归档 B0 `job.json` 的原始 command、intermediate_steps 中的工具名、参数和公开回执。只重放输入，不调用模型、网络、工具或仿真器，不修改原文件。
- 14 份 job 均有归档步骤；运行前冻结文件与实现 SHA-256。不得把 before/after、隐藏 checks、模型结论、几何筛查详情注入 ledger。screen 只用于样本身份，full-round1 索引只用于定位文件。
- 原 job 缺少可重建的工具调用 ID、开始/结束时序与并发分组。按归档顺序串行重放，并使用显式 audit ID；这不是原运行的精确时序恢复。每题使用独立空索引，不补造既往 blackboard。

## 主比较

v5 与 v7 接收相同原任务和回执，在初始及每条归档回执后读取投影。固定 3900 字符上限，逐前缀比较：原始 actor 与用户路线顺序、完整 route_projection、完成/剩余/未验证条款、落地与未知位置、原始事件、观察覆盖及来源引用、摘要长度和显式遗漏数量。未知和 omitted 不计作完成。

v7 是否启用 compact 分支按原始 command 判定。若模板导语或其他文本未被全覆盖，则回退 v5；不得删除原文后把新输入计作原题 compact 覆盖。

## 补充合成探针（与主样本分表）

对全部 14 个任务提取原文显式 route blocks，逐字拼接成 **新造的 route-block-only 指令**；明确它不是原任务。只用于覆盖 compact 分支和语义边界；用档案公开 list_drones 提取 actor 名称和 ID，缺失则记录缺口，不从私有世界填补。

每个派生指令固定六组**合成公开回执**：partial_prefix（各机半程）；wrong_actor（另一 actor 走首机路线）；out_of_order（漏第二点后先走后续点）；complete_then_land_without_coordinates（全部有序点＋无坐标落地）；landing_then_unknown_action（落地后效果未知动作）；empty_failed_unknown_observation（公开位置后空、失败、格式不足的感知）。每组使用新空 ledger，逐步骤检查。合成成功/部分完成/异常回执不证明真实物理执行和任务可达。

两版全量账本语义应相同；模型视图允许压缩，但每条可见事实必须有对应证据，剩余路线只能显示原始顺序前缀，省略必须计数，落地无坐标必须保持未知，局部空感知不能升级为全局不存在。若发现实质回归，只记录，不修改算法或重选样本。

## 结论边界与交付

产出独立脚本、冻结队列、逐任务/前缀结果、合成探针、汇总及报告。局部几何合法只保证原筛查定义下的局部空地，不保证连续路径、电量、时间或整题可执行。这14题属于已被历史分析接触的 B0 语料，不是盲测；真实轨迹固定后的投影一致也不证明模型会正确使用记忆，不能作为成功率、推理成本或跨任务泛化结果。后续在线验证仍需固定新任务/初态/模型/预算和自然决策协议。
