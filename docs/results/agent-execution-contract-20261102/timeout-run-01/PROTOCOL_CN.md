# 第二项：统一任务状态、失败恢复与完整运行链

日期：2026-11-02。此页冻结本地 `general-agent-v2-local` 的实现与验收契约，运行结果另见本轮报告。它承接第一项范围，不重新选择最优 Harness、不扩大自然能力或后训练结论。

## 目标与范围

在原工具与子程序两条路径中，使用同一份公开执行状态表示已请求、已确认、失败、部分完成与效果未知；明确剩余要求、恢复方式与停止边界。复用既有 ledger、frame 和真实工具回执，不引入任意自然语言义务图、自动任务分解或隐藏评分信息。

`general-agent-v2-local` 固定 `evidence_harness + observed_target_v7`，新增公开执行状态契约。调度可显式选择 `applicability/failure/fixed/every_step` 以做本地受控恢复验收；这不是自然模型择优结果。v1配置与历史运行封存不变，API/GUI默认不切换。

## 统一状态

- 保留原始任务全文、原ledger有限条款与实体绑定。未解析要求保持未知；不把有限投影当完整义务清单。
- 每个动作保留requested、effect_status、公开receipt来源、tool_call_id/evidence_id/plan_id；applied与remaining只来自明确回执字段，缺失为null。请求值不能冒充实际执行值，后来的状态查询不改写过去的未知回执。
- 原工具调用与子程序内部调用统一记录，但确定性程序动作不冒充模型决策。skill completed只表示子程序停止条件，mission_completion始终not_evaluated。
- 模型只获得有限的恢复建议投影，原文与原工具回执继续保留。公开状态文件与独立评分分开，checker/private snapshot不进入策略。

## 恢复与停止

| 情况 | 契约 |
| --- | --- |
| 明确失败 | 保留主体、原请求和失败反馈；允许模型核查前置条件后组织原工具修复，不自动重试 |
| 部分完成 | 区分明确已完成部分与剩余/未知部分，不重放整条动作链 |
| 效果未知 | 先公开查询相关状态；不得由异常推断无副作用，也不得把请求参数当完成效果 |
| ready/paused且仍有效 | 才能恢复同一plan；须保留实际cursor和既有动作 |
| 依赖变化或needs_replan | 原计划不可恢复；模型可按新反馈组织原工具继续 |
| completed/cancelled等终态 | 拒绝resume，不重放动作；整题其他条款仍单独核查 |
| 回合结束、截止或取消 | 全局停止优先，不再提供可执行的恢复机会；不撤销已发生动作 |

恢复建议不是通用自动恢复器。当前可恢复机会与实际恢复成功分母分开；没有机会时恢复率为null。

## 完整运行链

维护入口仍为 `scripts/general_agent.py prepare/run/verify`，v2通过显式profile选择。任务、初态、脚本响应、源码、预算、协议绑定冻结manifest；父进程串行启动新worker，持久记录start/exit并join；worker关闭准入、冻结世界、排空请求、封存后，独立scorer才可运行。

回合终止、归档完整性、批次是否继续和任务评分是四个不同结论。`episode_termination`纯分类器只有在父进程验证退出封存后才提供评分资格：

- 正常返回、已知usage的token/HTTP次数预算结束，可继续本manifest剩余已授权槽。正常预算结束产生的partial归档保留并评分，不自动进入训练。
- 取消停止整批；单请求超时、传输异常与任务总预算区分。
- 原DeepSeek小批的封存协议仍是请求停止即停批；本契约不追补其未运行槽，不新增付费调用。在线成本分类器用Mock/纯账本检验，不把它算作新增provider实测。

## 验收方法

固定开发任务初态、实际Agent/SDK与本地ASGI仿真，模型输出使用显式脚本；禁止外部网络。正常、原工具修复、提交后丢回执、暂停恢复、失效后原工具接续、终态拒绝、预算续槽、未知usage停批、取消/超时等按预先写定的用例核验。

`api_fault=response_lost`仅在v2本地受控用例中允许：真实动作完成后向调用者抛出异常，私有日志标记注入。策略不能读该标记，必须使用公开状态；它不代表真实故障概率或自然模型能力。部分/矛盾回执等不能安全从固定仿真任务构造的边界另作模块测试，不混入回合分母。

所有失败、partial、未评分及未运行槽均保留。代码测试、本地回合、真实模型实验分别计数。正式Teacher转换、独立数据划分、学生训练和跨任务自然评价仍属后续工作。
