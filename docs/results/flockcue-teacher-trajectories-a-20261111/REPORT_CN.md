# 首批真实 DeepSeek 教师轨迹 · A 折

11 月 11 日，从正式 600 题 FlockCue + DeepSeek 首遍中重建 A 折全部 300 道题。3,417 个训练侧和 1,009 个内部验证侧决策轮已导出并核对当轮模型实际输入、真实回复与动作回执。完成训练侧 240 个题位的逐题筛查和取舍，获得 **110 题、386 个经审阅且可在当前 Qwen3.5-2B 原生模板中完整表示的决策轮**。整理使用封存原件和本机 CPU，新增教师调用、GPU 卡时、权重更新均为零。

## 从工具调用到题面要求

全 A 折 4,435 次 HTTP 尝试对应 4,431 个逻辑轮。模型发出的 6,717 个工具调用中，有 6,711 个可绑定真实回执。5 个无法完整重建的逻辑轮保留在索引里。公开包中每轮的四个字段为 messages、tools、target、post_action_receipts。构造本轮输入时只用前两项，后置回执从后续决策起才可见。逐行复查了回执 ID、哈希以及预定私有检查标记。独立检查的结果、取舍理由、原件路径均在旁表。[公开格式与可定位原件](WIRE_FORMAT_CN.md) · [公开边界核查](public-boundary-audit.json) · [原始文件封存](source-seals.json)

对 300 道题重放了原终态的 1,930 个叶检查，并独立重建题初状态。25 题在接收本轮指令前已满足检查。终态冻结 JSON 缺少机上临时动作历史，单用它重算会改变 201 题的整题判定。终态使用冻结时保存的真实检查 API 回包。原评测分数与示范取舍分别记账。[初态、终态与新增物理动作](initial-final-a.jsonl) · [重放方法及交叉验证](initial-final-method.json)

训练侧 240 题的审阅结论为 157 题通过、35 题证据不足、48 题排除。其中有 13 道巡逻题的动作支持整题完成，但本次审阅没有从中选入整轮可学习的教师回复。通过审阅的另外 144 题各有至少一轮获提名。

巡逻场景 04cd6269 第 9 题要求至少悬停 19 秒，悬停命令参数为 20 秒，从命令时刻到环境冻结只有 8.804 秒。这道题保留原评分，实际悬停时长的证据不足，未纳入示范。目标分配场景 7f1a1456 第 1 题则由一次 simple_chain 调用触发三条有序物理指令，分别是起飞 13 米、转向 206°、悬停；模型只产生一次子程序调用。[巡逻逐题审阅](review-04cd6269.jsonl) · [搜索与目标分配交叉核查样例](review-search-assignment-examples.jsonl)

对训练侧全部 193 道机械候选题的 2,532 个可重建轮，逐一投影至固定的学生模板，1,195 轮通过工具解析、目标回放及长度检查，1,337 轮超出现行总长 32,768 或目标 2,048 token 的边界。按题面、实际行动及回执进一步提名 627 轮，其中 241 轮超长。保留下来的 386 轮覆盖 129,010 个潜在监督 token，其中教师原生思考 83,907 个。该计数用于估算后续 SFT 数据规模。长轮仍保存在原始公开包。

训练侧 240 道题的首个请求都在 32,768 个学生 prompt token 以内，最末请求单看 prompt 已有 161 个超过该值。直接截断会影响后段行动与回执；SFT 定稿时应按题族和决策位置报告损失。接口复核采用原生模板、单一的“保留实际教师推理”表示，验证当轮目标能回放原始工具参数；并行工具的组序已与原始调用对应。[240 题首末轮计数](qwen-training-boundaries.csv) · [2,532 轮全量投影判定](training-candidate-qwen-audit.jsonl) · [现有学生编码与回放](../../../scripts/flockcue_qwen35/dev_sample_tokens.py)

当前可移交的轮次中，381 轮发出工具调用，只有 5 轮仅输出文本。314 轮含原生教师思考。110 道入选题中，只有 5 道的每个逻辑轮都进入此包。较多提名集中在证据清楚的执行动作，后续做 SFT 时，应从相同训练侧定向复审有回执支撑的完成回复与失败恢复轮。保留数据量足以制作首版样例，整题效果需以学生上线实测。
