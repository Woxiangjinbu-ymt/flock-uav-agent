# Harness 飞行状态 v3：同初态离线配对验证协议

预定日期：2026-10-23。执行前确定本协议。用户已授权验证 `idle + z>0` 问题及最小修复，并检查修复后能否完成整题。本批独立于已封存的入口契约批次；不改旧 runner、旧结果、原 fixture、任务或 checker。候选功能测试完成后才冻结源码并派发 trial。

## 假设与比较

入口契约批次的 `24ac1838` 在公开状态 `idle`、高度 57、满电时直接 move，得到 `Cannot move from current status: DroneStatus.IDLE`。原搜索用高度及缓存判断 airborne，存在“高度大于零即可以移动”的不可靠推断。

基准为 `entry_contract_v2`，候选为 opt-in `flight_state_v3`。两臂均使用空黑板公开入口、`applicability` 调度及相同搜索策略。候选仅让公开状态决定起飞/移动合法性：`idle/ready` 先起飞，`hovering/flying/moving` 可移动，未知或不可用状态退出；成功起飞后再次公开读取并验证可移动状态。起飞仍用原 20 米参数，失败仍沿用原禁用 actor 和修复预算。默认 revision 保持原值。

这是代码功能与整题结果的两个独立检验：消除 IDLE move 并不保证搜索达到任务门槛。预期可能继续遇到障碍、候选区域或预算限制，均如实保留，不以更换样本或搜索算法制造成功。

## 预算、冻结和停止

两臂相同：任务 deadline 500 秒、每计划 API 2,000、局部修复预算 16、搜索上限 16 轮。所有 trial 使用同一份预先复制并哈希的 agent/server/runner 源码；不得在批次中途修改候选后继续派发。外层每 trial 90 秒墙钟 watchdog，触发记为不完整，不冒充经过 500 秒或 checker 失败。

新输出目录必须不存在。固定 14 次；基础设施、哈希、预算配置、网络、checker 错误或终态控制探针不满足时停止剩余派发，保留原始产物。`needs_replan`、unsupported、预算耗尽和 checker 不通过均是有效观测，不触发自动重试。

保留所有 API/回执、物理事件、计划/门控、原 checker 树、初态/结束哈希。运行前后核验 fixture 和冻结源码；运行结束单独封存新批次文件。

## 指标与公开证据定义

主结果为原整题 checker 是否通过及子检查分母；同时记录公开 progress/已访问目标、skill status/reason/cursor/repairs、API/动作/路径/耗电与实际用时。进度上涨或技能局部修复不能替代整题通过。

逐条公开动作记录关联最近一次同 actor 的技能公开状态读取（或技能 fleet 读取），包括状态请求 ID、position/status/battery、动作及回执；不引用 preparation、私有快照、checker 数据归因。状态到后续物理动作的关联是观察统计，不声称覆盖没有动作的所有内部决策。

- **状态触发**：后续动作前的公开状态为 `idle/ready`，单列其中 `z>0`，按所关联动作计数并提供唯一 actor 数及 request IDs。两臂同口径；v2 可能直接 move，v3 应先 take_off。每次新状态读取后首次后续动作可作为一次触发事件，不能把重复读取当多次触发。
- **起飞效果**：每次 take_off 的公开前置状态、真实回执，以及下一次同 actor 的公开状态；区分零高度常规起飞与正高度触发。未出现某类状态不能宣称验证过该类。
- **非法移动残留**：move 前最近公开状态为 idle/ready 的动作数，以及回执含 `DroneStatus.IDLE` 的次数与事件。前者是观测前提，后者是实际模拟器错误。
- **首次动作分歧**：按物理动作顺序比较 `method/endpoint/params/body`，报告最长相同前缀及首次不同的动作与其公开前置证据；不把时间戳、request ID、plan ID 差异当策略差异。另比较动作总数和最终停止原因。
- **终态幂等**：首次 start 后重复 start，再对终态 resume，必须明确拒绝且 `resumable=false`（unsupported 无 plan 时单列）；完整 frames、世界 hash、API 数与物理事件数不得改变。

另将本批 v2 与入口契约封存批次 `run-20261023-01` 的同名 v2 臂作诊断核对：初态 hash、规范化动作序列、公开进度、停止原因、原 checker。历史批次只作可复现性诊断，不替代本批并行基准；若时间或环境差异造成变化，披露变化而不为追求一致改协议重跑。

仅在这组已知固定任务、明确选择技能、同初态预算条件下解释结果；不是 LLM 端到端任务成功率、独立泛化或模型能力提升证据。保留成功和失败的固定分母。
