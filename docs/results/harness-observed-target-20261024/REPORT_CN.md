# 已观察固定目标跟进：v6 / v7 独立对照

日期：2026-10-24。**已完成 7 题 × 两版、14 次固定初态模拟器执行；搜索整题成功仍为 1/3→1/3。** 新候选改善了两个失败题的部分进度，并降低一个原本成功题的执行成本；没有解决剩余两个整题，也不能据此宣称泛化或论文创新。候选 `observed_target_v7` 保留为显式可选版本，默认仍为 legacy。本批不与此前 v2–v6 结果混合。

## 为什么做这一项

先完成两题的公开前缀审计：[7eba 诊断](../harness-residual-audit-20261024/7EBA_PUBLIC_DIAGNOSIS_CN.md)复现 80/80 次选择，确认 Fixed Target 2 在 #43、#289 已被看到，原探索路径仍未进入其任务半径；Fixed Target 1 则已有正向到达回执，后续 `is_reached=false` 不能反证未完成。[24ac 诊断](../harness-residual-audit-20261024/24AC_DIAGNOSIS_CN.md)复现 126/126 次选择：17 次失败所指障碍均未在此前公开 nearby 中出现，三条失败路径没有同边/反向边复用机会，因此没有继续添加路径共享或新 planner。

本次只检验“已经发现的固定目标是否值得用正常行动槽跟进”。不改变格点范围、密度、评分、飞行高度、全局预算、修复上限或服务端语义。审计另发现的圆形近似外漏没有造成上述 17 次失败，本轮保留为独立正确性待办，没有顺带修改几何算法。

## 候选实现与证据边界

- 只从当前计划真实收到的有效 nearby 登记固定目标：有限 XYZ、有效 ID、规范 `Fixed Target N` 名称；首次发现者负责，最多安排一次定向尝试。继承黑板中缺本计划来源的目标不进入候选，也不推断未发现目标。
- 使用发现者正常轮次中的一个动作槽，保持 z=20；fresh 状态需有有限正 task_radius，且 `abs(20-target_z)<=task_radius`。沿用公开几何、精确 XYZ 共享屏蔽、同 actor/起点失败记忆及后读核验，不新增 API 读、跟进重试或任务预算。
- 定向点有独立稳定索引及按真实 XY 计算的覆盖；普通探索排除定向索引。同坐标的格点/定向点不能借新索引绕过已有失败，换起点仍保留原路径条件。
- 同 ID 的位置、名字或类型变化后禁用；同名不同 ID、未知身份也保守禁用。只尝试公开观测坐标，不保证目标仍在或道路实际可通。无额外“静态目标”假设。
- `is_reached=false` 完全不用于 remaining 判断。合格成功 move 的名字回执、以及 nearby 的明确 true 标记，仅抑制可选跟进，**均不生成 target ID 完成标签或整题完成结论**。完成仍由技能自己的公开 progress 严格 >95 确认，原 checker 独立执行。

实现见 [目标跟进模块](../../../agent4drone/observed_target_search.py)、[技能接线](../../../agent4drone/harness_skills.py)、[runtime](../../../agent4drone/harness_core.py)、[工具接线](../../../agent4drone/harness_integration.py)。[代码审查](CODE_REVIEW_CN.md)保留三项在执行前发现并修复的问题及证据；[增量补丁](candidate-change.patch)只包含本候选改动。

## 真实触发与负面变化

本批 v7 共登记 **38 个调度项，38 次均实际发出并返回**，按任务为 1、31、6 次；均有动作成功及对应规范目标名字的到达回执。没有 scheduled-only、未知效果、变化禁用或 true 标记抑制的真实触发；这些边界仅有代码测试，不混入真实任务分母。38 次到达回执不等于相对基准多完成 38 个目标，因为后续探索轨迹及已有访问集合也变化。

`7eba7390` 首次分歧是第 15 个动作 / #61：用 #43 已观察的 Target 2 中心 (524,712,20) 替换原格点 (411,665,20)，回执明确到达 Fixed Target 2。它只跟进一次，Target 1 的名字正证据阻止重复跟进；第三目标仍未观测到。之后探索改变，在 #107、#123 分别撞上同一多边形的两个不同终点 (481,315,20)、(481,385,20)，**新增两次错误，不是同 XYZ 重复**。因此不能写成无代价改善或完整解题。

24ac 首次分歧为第 12 个动作 / #97：依据 #39 观察，访问 Fixed Target 37 中心，替换原会撞障碍的格点；最终多访问 13 个目标，但仍消耗 17 次失败。b1ad 首次分歧为第 14 个动作 / #73：依据 #25 观察跟进 Fixed Target 15，最后在第 110 次移动尝试的常规进度读取确认 100%，较基准 176 次移动更早完成。每次来源、动作、后读与抑制证据见各 trial 的 `observed-target-diagnostics.json`；不以名字回执自行推导某个 ID 完成。

独立审计的 618 项实验不变量全部通过，另将 7 项历史成本比较中的 5 项相同、2 项耗电差异单列，见 [INDEPENDENT_AUDIT_CN.md](INDEPENDENT_AUDIT_CN.md)及其机器证据。以上是已开发静态场景中、确定性技能显式入口的有界验证，不是自然 LLM 选择技能的收益、独立测试集泛化、Teacher 轨迹或后训练成果。

## 下一步与收束决定

保留 v7 为可对照的候选，尚不修改默认或宣布稳定通用搜索器。发现后跟进缺口已有局部正证据，可暂时停止为这三道开发题继续堆叠搜索机制；两个未完成题的覆盖/未发现目标和未知障碍限制仍如实保留，不追加预算或自动重跑。

下一优先级是 [收束接口审查](../harness-residual-audit-20261024/CLOSEOUT_REVIEW_CN.md)指出的两项：完整 episode reset 及隔离、可重建的模型实际输入/动作轨迹。先固定可复用运行契约，再单独冻结自然 Agent 的选择/接手验证；不启动旧 360 次，不把确定性 skill 动作序列直接当 Teacher 示范，不立即进入 SFT/RL。

本轮修改 3 个 Harness 接线文件，新增目标跟进模块、专项测试和独立 runner；更新研究状态/Roadmap，并新增本批报告、审查、诊断、协议及封存材料。稳定研究路线与 AGENTS 保持不变。
