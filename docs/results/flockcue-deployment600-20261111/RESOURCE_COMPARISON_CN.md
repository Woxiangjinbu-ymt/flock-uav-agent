# 同一 600 题的用量与耗时

两期均取冻结的 30 个场景、各 20 题的首次部署。请求数和 token 只计评测题，网关预检单列在主报告中。

| 指标 | 十月 Agent4Drone | 十一月 FlockCue |
| --- | ---: | ---: |
| 已启动评测题数 | 600 | 600 |
| 模型 HTTP 尝试数 | 8,096 | 8,659 |
| 返回 usage 的请求数 | 8,080 | 8,655 |
| 有缓存拆分的请求数 | 8,080 | 8,655 |
| 输入 token | 489,246,261 | 502,018,154 |
| 其中缓存命中 | 463,033,600 | 378,178,176 |
| 其中缓存未命中 | 26,212,661 | 123,839,978 |
| 输出 token | 13,607,438 | 7,852,296 |
| 已知总 token | 502,853,699 | 509,870,450 |
| 其中已知思考 token | 未记录 | 6,450,570（n=8,655） |
| 单次 HTTP 耗时 P50 / P95（秒） | 2.82 / 30.28（n=8,096） | 2.59 / 21.81（n=8,659） |
| worker 作业耗时 P50 / P95（秒） | 54.08 / 384.25（n=600） | 43.19 / 343.74（n=600） |
| 动作窗口开启至环境冻结 P50 / P95（秒） | 56.36 / 388.11（n=600） | 45.70 / 347.15（n=600） |
| 终止性供应商 HTTP 错误计败题数 | 14 | 0 |
| 传输层错误尝试数 | 0 | 4 |
| 重试 HTTP 尝试数 | 2 | 4 |

按已返回的用量，本次合计 token 比十月增加 1.40%。输入含每次重发的上下文。十月只留下归一化 usage，无法比较两期思考 token 的变化。[十月逐题历史数据](../baseline-deployment-20261005/tasks.csv) · [本次逐请求数据](calls.csv)

HTTP 时延覆盖有结束或错误事件的尝试。worker 耗时取作业启动至结束的单调时钟，环境冻结耗时取 frozen_at − opened_at，包含动作窗口关闭及在途请求排空。P50、P95 在全部有观测值的样本上采用线性插值，n 表示该项实际样本数。[原始计量代码](../../../scripts/reproduction_metrics.py) · [本次评分及冻结时间](tasks.csv)

十月记录 2 次 HTTP 429，均属于同一次逻辑调用，该调用最终返回 402。十月因终止性 402 计败的有 14 题。本期传输错误可能由 SDK 重试恢复，统计尝试和统计最终失败题时分别计数。十月缺少该子集实际账户结算。[十月原始日志](../../../experiments/runs/20261003-143255-full-5c501118/) · [正式报告](REPORT_CN.md) · [汇总原表](summary.json)
