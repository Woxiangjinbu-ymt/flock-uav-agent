# DeepSeek 整合前后自然行为小批验证

日期：2026-11-02。**已观察到模型行为变化，但没有得到整合版普遍更好的证据。** 短链题中模型自主选择了子程序，模型请求和 token 减少；原工具导航题中出现参数错误后修正及额外状态查询，开销增加。两个完整配对都双方成功。搜索基线触及 token 停线后，本批停止；搜索整合臂未执行，不能比较其搜索或失败恢复收益。

这是用户明确授权的小规模真实 DeepSeek API 验证。仿真世界仍在本地；不涉及真实无人机、不续跑旧360次或14槽队列、不进行Teacher生产/SFT/RL。规划6回合，**实际启动并独立评分5回合，保留1个未运行槽**；正式分母与停止状态见 [summary](run-01/summary.json)，执行前冻结的[协议](run-01/PROTOCOL_CN.md)与[manifest](run-01/manifest.json)保持原样。

## 版本、任务与可比较边界

- B：当前维护源码 `task_progress_mode=off` 的原工具参考臂；使用相同的新worker、时限、归档和独立scorer。它不是直接拿历史1500题成绩充当同期基线，也不是宣称完整复现1500题时的旧源码。
- I：`evidence_harness + observed_target_v7 + applicability`，不叠加 execution_memory_v7。I增加R2状态上下文、`run_harness`，在显式进度任务中增加公开进度工具；两臂原始动作工具和物理API权限相同。这是整合系统包对照，不能把差异单独归因于调度、记忆或共享。
- 模型请求为官方 `deepseek-flash`，`thinking=enabled / reasoning_effort=high`，SDK与HTTP传输重试均0。37个真实响应均返回 `model=deepseek-flash`，fingerprint均为 `bc19ba97cbe016479903222bb1578db6`。响应未提供不可变权重版本；官网滚动版本名不替代账户响应证据。
- 固定3道已知开发任务，来自同一个5 UAV / 3目标 / 6障碍场景。按小场景与短链、原工具导航、搜索三种职责选题，各臂每题一次；不是独立泛化、F1–F6完整覆盖或统计显著性试验。

两个完整配对内，B与I均2/2通过。合计模型HTTP为13→12，但token为143,662→151,183，增加7,521（约5.2%）；因此不能用短链的局部下降宣称总体token节省，更不能将B的2/3与I的2/2直接比较成成功率提升。

**短链的自然选择有直接证据。** I进入时frames=0，模型先查询无人机，再自主调用 `run_harness(start, simple_chain)`；程序执行Drone 1起飞15m、转向96°、悬停，模型随后调用状态查询。两臂三项动作的主体、顺序与参数相同，均无重放。原checker仅查高度和航向，悬停另由公开回执和物理 `hovering` 事件补证。任务期公开API次数从B的10增至I的15，说明模型调用节省伴随程序内部检查增加，不是所有成本都降低。

**导航的额外开销可定位。** I第一次将 `sense_nearby_entities` 参数写成 `{}`，模型实际收到 `input_json: Field required`；下一次调用补全 `input_json` 后获得观测。之后额外显式查询两次无人机状态，B为0次。两臂最终均起飞、到达 `(544,393,15)` 并悬停，没有提交子程序，也没有遗漏这三个动作。该原checker只查到达坐标，悬停效果另审计；任务期公开API为13→15。不能凭一次样本将额外查询全部判为无用，也不能把修正参数等同于验证了Harness失败恢复收益。

**搜索基线暴露了待验证的问题。** B起飞5机并执行25次导航、1次升高，共31动作尝试，其中30成功、1次目的点障碍冲突。公开反馈已经发现 `Fixed Target 1`（`11485ece`，`626,345,0`），下一模型批次仍向五个新的扫描点移动，未跟进该目标。截止时原会话进度为0%。未见重复起飞或同一失败目的点重试；起飞前后的全队感知参数相同，不能仅据重复参数认定无效。由于I未执行，本批只能提出“已见目标反馈没有及时转成后续动作”的观察，不能声称v7已经解决它。

**没有真实可恢复的暂停机会。** 已执行I仅有一条短链，直接completed；没有ready/paused且resumable=true的返回。因此resume有效率、终态后原工具继续成功率均不可估计，不能写成0%或100%。逐条call ID、帧、错误回执与动作证据见[机器分析](analysis-03/analysis.json)及[详细轨迹报告](analysis-03/REPORT_CN.md)。分析不公开完整reasoning内容。
