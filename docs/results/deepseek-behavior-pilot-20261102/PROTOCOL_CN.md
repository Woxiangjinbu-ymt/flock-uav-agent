# DeepSeek 自然行为小批验证协议

日期：2026-11-02。源码、输入及本协议须在首次派发前随运行清单冻结。** 用户已授权本轮小规模 DeepSeek API 验证；本文件不复用旧 360 次队列或旧 14 槽授权，也不授权扩量、Teacher 生产或训练。真实模型通过网络服务运行，任务世界仍是每回合隔离的本地仿真，不涉及真实无人机飞行。

## 1. 问题与对照

观察同一 DeepSeek 配置在原工具 Agent 与整合 Agent 中如何选择动作，是否自主选择子程序，是否保留超出子程序语法的义务，以及遇到失败或终态后能否继续推进原任务。本批是已知开发场景的描述性行为 pilot，不是独立泛化，也不是完整 F1–F6 整体覆盖评价。

| 臂 | 固定配置 | 解释范围 |
| --- | --- | --- |
| B：原工具基线 | `task_progress_mode=off`；保留原工具、相同新回合/归档/隔离评分协议 | 同期运行结果，不拿旧历史模型成绩作基线 |
| I：整合候选 | `evidence_harness + observed_target_v7 + applicability`；静态障碍契约；不叠加 `execution_memory_v7` | R2 反馈、状态上下文和子程序能力的整合效果 |

两臂使用相同原始动作工具、物理 API 权限、模型参数、初态、任务文字、预算及 scorer。I 臂新增 `run_harness`、R2 上下文；在显式会话进度题中还追加 `get_mission_progress`，B 臂保留 `off` 原样。因此工具 schema 和全部策略输入不相同；这是整合系统包对照，不能将差异单独归因于调度、记忆、共享或某一修复。旧 [7 题/14 槽](../../HARNESS_NATURAL_AGENT_VALIDATION_CN.md)是 A/F 调度对照，不与本批混合。

## 2. 候选选题与固定规模

固定 3 题 × 2 臂，各一次，共 6 回合；采用最小现成开发场景中的三种不同职责，**不按历史最好成绩选题**。全部来自 [`minimal-harness-full100-v1/fixtures`](../../../experiments/minimal-harness-full100-v1/fixtures/)，保留原指令、snapshot、timeline 和 checker，不改地图制造故障。

| 次序 | task ID / 原指令摘要 | 长度与执行主体 | 重点 | 原 checker 边界 |
| --- | --- | --- | --- | --- |
| 1 | `c00d8b78`：Drone 1 起飞到 15m，转向 96°，悬停 | 98 字符 / 18 个空白分词；指定 1 UAV | 完整 `simple_chain` 语法；观察模型是否自行提交，完成后是否重复动作 | 2 叶：航向、高度；不单独查悬停，需另审计 hover 回执 |
| 2 | `b4714028`：Drone 3 起飞到 15m，访问 `(544,393,15)`，短暂悬停 | 96 字符 / 18 个空白分词；指定 1 UAV | 起飞/悬停之外还有坐标访问，完整语法不受子程序支持；看原工具选择与义务遗漏 | 1 叶：本回合访问指定位置；不单独查最终悬停 |
| 3 | `7eba7390`：选择必要 UAV，访问目标至会话进度严格超过 95% | 125 字符 / 20 个空白分词；由模型选必要 UAV | `public_search` 自主选择、搜索失败后的继续/停止、真实效果与最终声明一致性 | 1 叶：原会话进度检查；保持原实现，不据工具状态改评分 |

三题均位于 `scene_id=3973d0d6`，原场景有 **5 UAV / 3 targets / 6 obstacles**；三题各自初始 checker 均为失败。它们是 **3 个任务、1 个场景**，不是三个独立场景。所有 UAV 初始空闲、地面、100% 电量；准备阶段的信息仅供评估核查，不预填策略黑板。

不选择更大旧题的理由是本轮有界行为观察：`784d71f8 / 24ac1838` 的原场景为 30 UAV / 100 targets / 100 obstacles；`1905e0ad / b1ad4f3e` 为 15 / 20 / 20。其难度、历史成本和覆盖价值留待独立批次，不将本批小场景结果外推到这些规模。

固定顺序为 `c00d8b78 B→I`、`b4714028 I→B`、`7eba7390 B→I`；槽位 ID 随清单冻结。各对恢复同一初态、新建 worker，不能让前一臂的世界或黑板污染后一臂。3 对不完全平衡，不为凑平衡追加回合；本批不设运行中候补任务。

## 3. 恢复机会的先验依据与限制

[`7eba7390` 的旧脚本证据](../harness-natural-agent-preparation-20261025/CHECKPOINT_EVIDENCE_CN.md)记录 2 个移动受阻、仍在局部修复预算内的候选检查点；当时是脚本显式 start、`applicability` 调度，实际模型调用与 paused exit 均为 0，最终 `needs_replan / round_limit_below_threshold`，公开进度 66%。这支持观察失败处理与终态后续行为的选题价值，**不保证新模型会选子程序、到达同一状态或出现可 resume 机会**。

本轮 I 仍为 `applicability`；自动局部修复并继续不等于模型恢复。只有真实返回 `ready/paused` 且 `resumable=true`、计划有效、剩余预算充足时才统计同计划恢复机会。`needs_replan/completed/cancelled` 上的 resume 属控制误用；终态后模型使用原工具推进剩余义务另列，不能混入 resume 成功率。机会为零时写“不可估计”，不追加/重跑任务凑分母。

## 4. 自然入口、记录与预算

自然入口只提供原任务、固定基础系统提示、按臂生成的公开工具/状态以及实际反馈；禁止 bootstrap 计划、私有 fixture 字段、适用性标签、checker、候选检查点或 oracle 位置进入策略。模型未用子程序但原工具完成，同样计任务成功。

维持每回合新 worker → 完整归档 → 请求排空/退出 → 父进程封存 → 独立 scorer。静态契约由本地独占世界和写入隔离落实，不只写一个环境变量。保存 profile/源码/输入哈希、原始请求响应、logical/attempt/tool call ID、公开回执、子程序/模型动作来源、物理动作和三层结果。

| 项目 | 本批固定值 |
| --- | --- |
| Provider / 模型候选 | 官方 DeepSeek / `deepseek-flash`；实际响应 model、请求 ID 与行为按原始响应记录，官方滚动别名不等于固定权重 |
| 推理配置 | `thinking=enabled`、`reasoning_effort=high`；实际 wire 核验，不以旧 temperature 草案替代 |
| SDK 重试 | 0；失败不自动补跑 |
| 回合 / 请求 / 排空 / watchdog | 500s / 60s / 5s / 515s；真实单调时钟 |
| 请求与输出 | 每回合最多 12 HTTP attempts；每请求 `max_tokens=8192`；仅 chat，不启用单独收费的 search/fetch API |
| 累计 usage 停线 | 每回合 200,000 token，完整响应后结算并停止后续准入；不是精确调用前 token 硬上限 |
| HTTP 正文大小 | 200,000 bytes；只约束序列化请求正文大小，不当作 token 数 |
| 原执行预算 | 600 迭代/工具步设置、1,800 recursion；每计划 2,000 API、16 repairs、16 search rounds；按原实现作用范围，不冒充 raw 工具全回合 API 上限 |
| — | — |
| 保守费率 / 上下文上界 | — |

这里保守使用 cache-miss/峰值价格；不把缓存折扣或旧模型价格预先算作可用额度。实际 usage、响应和可核对成本另行保存。

全部两臂基础模型参数相同，不逐题调参。币种与上述限额是本轮已授权小规模验证采用的保守执行配置，不启动旧计划，也不将剩余额度自动转为新任务。

## 5. 分析与停止规则

主指标为原 checker 的逐题端到端成功；完整配对上报告 I−B 差异，不将少量样本差异写成稳定增益或显著机制效果。并列 `run / public_evidence / independent_evaluation`，区分正常返回、模型声明、子程序终态与隔离评分。

| 分析项 | 保存/统计方式 |
| --- | --- |
| 自主路径选择 | 实际模型 `start` call ID、plan_commit/skill_enter；原工具直接执行；不支持时的控制拒绝 |
| 义务执行 | 指定 UAV 绑定、真实动作顺序/效果、未执行条款；悬停等原 checker 未覆盖要求单列，不修改原评分 |
| 失败与后续 | 失败类型、实际剩余要求、修复动作、终态后原工具推进、重复已生效动作和错误 resume |
| 恢复分母 | 有效计划真实 paused/ready 机会、正确 resume 尝试、实际恢复执行；事件/轨迹/task/scene 数分别列出 |
| 预算与成本 | — |
| 完整性 | 初态/源码/权限、归档 complete/partial、调用关联、worker 排空/退出、scorer 输入哈希 |

合法任务失败、技能不适用或按协议达到回合时限保留为结果，不据结果临时换题。半对停止则报告已执行回合和未运行槽，不把未运行记作任务失败，不擅自补齐。完整材料可用于分析数据格式，但本批不是正式 Teacher 数据集。
