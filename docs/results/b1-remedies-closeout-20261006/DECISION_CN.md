## 论文定位与下一阶段

B1 是具有已观察收益的修正基线。六页论文无需再把补救工具、重试、超时、验证器分别扩展成贡献；主线应由后续一个有机制证据的协作执行改进承担。本轮适合用于开发动机、基线选择与失败分析，不能替代最终受控主实验。

当前证据没有认证每个补救模块：距离工具没有产生新增成功的证据，覆盖句柄恢复未触发；覆盖相关收益含前题状态继承。唯一回归与题前目标知识差异有关，不能简单归因于单个改动。历史 B0 与 B1 的日期、并发和动态题前状态不同；同 57 题的 token 从 39,596,960 增至 48,948,005，也不能声称所有资源指标改善。

下一阶段固定为 **M1 = M0 + 最小任务进展与证据状态**，先核对旁路回放和可关闭性，再进入预先固定的开发集性能筛查。保留原模型循环、工具能力和评分标准；不同时加入独立验证器、复杂预算控制或多套恢复策略。M2 的具体行动机制由残余失败证据决定，发现到指定执行的交接只是优先候选；M3 为可选恢复增量，只有对任务成功率有明确帮助才投入。

后续在线比较应另建 attempt，运行冻结 B1 与增量版的同期同协议对照，并保留新增成功、回归、成本和场景继承信息。下一轮启动前检查运行生命周期和落盘可靠性；中断根因尚未确定，不将其写成 B1 算法失败。关闭全部新增机制应恢复 M0；架构继承可保证，成功率单调提升需实测。
