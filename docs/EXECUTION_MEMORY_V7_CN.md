# 执行记忆第七版：只精简路线任务，其他任务沿用 v5

第六版三轮对照出现四次线索搜索失败，整体用量增加。因此不把它整体替换 v5，改为缩小适用范围。

验证已完成：[结果报告](results/execution-memory-v7-20261016/REPORT_CN.md)。两版均 12/12 成功、完成后额外调用为零；路线任务在相同调用次数下用量下降 5.64%。本次两个批次总用量 562,153 token，没有扩大场景或追加补跑。

## 固定改动

仅对原始指令中完整支持、没有额外未知子句的显式路线，采用 v6 的续做清单与落地位置说明。任务资格按原始语法固定，不依赖执行结果、案例编号或当前完成情况。

其余任务每次给模型的记忆内容逐字沿用 v5，包括访问已经完成后的读取点。新版本标记只写入审计，不额外进入提示。保留所有原始工具回执，不拦截调用、不自动结束、不为报告补查坐标。

## 新的验证批次

这是一项看过 v6 失败后的探索修正。旧 v6 三轮 36 次完整保留，另以新跑的 v5 为基线，固定两轮：原六个场景 × 两个版本 × 两轮，共 24 次。不扩大场景，不挑选重跑，两个批次不混合统计。

模型和单次预算沿用前批：`deepseek-flash`、温度 0.1、关闭 thinking；每次最多六次模型调用、十二次工具调用、90 秒、60,000 token。每轮上限 200,000 token。

**两批总额度为 600,000 token。准备时封存前批用量和哈希，后批每次请求先预留额度；未知用量按预留计。若不够，保留预算停止和未执行记录，不补样。

路线场景主要验证必要步骤、完成后额外动作、提示成本和落地表述；非路线场景验证逐字回退与执行情况。两版在非路线场景中的提示相同，随机执行差异不能归因于 v7 的改进。

所有结果仍是这六个开发场景中的观察，不能替代独立任务验证。
