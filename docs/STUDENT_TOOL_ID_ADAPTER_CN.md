# 学生工具调用 ID 适配 v2：方案与验收协议

日期：2026-11-03。根据第四项后续要求，处理 v1 因原生模板不打印调用 ID 而拒绝的同名并行历史。本轮是本地输入兼容尝试，不调用 provider、不下载权重、不训练。v1 代码、原始归档和验收包保留，后续结论另写报告。

## Confirmed Decisions — 选择的方案

v1 的保守规则不等于 Qwen3 天生不能处理同名工具。已有调用 ID 足以确定关联，问题在于送给学生的文本省略了它。三种可行方向如下：

| 方案 | 适用范围与代价 |
| --- | --- |
| 原生模板按位置匹配 | 最小改动，但必须保证完整回执与调用顺序一致，并明确顺序语义；无法保持任意乱序历史的显式身份 |
| 历史调用和回执显式 ID（本轮选择） | 保留并行、同名与实际返回顺序；增加少量输入 token，需统一训练与推理模板并验证模型适应情况 |
| 所有工具串行执行 | 格式简单，但会改变动作调度、时延及多机协作行为，不能当作无代价的输入修复 |

采用固定 Qwen3-1.7B tokenizer，另建版本化模板。角色 token、非思考 generation prefix 和当前输出的工具名/参数语法沿用原生格式；历史 tool_call 增加 `id`，tool_response 使用包含 `id/name/content` 的 JSON 包装。回执原始内容完整保留为字符串，不能借包装删字段、改值或添加私有状态。

原始供应商 ID 在输入准备时按历史调用顺序映射为 `call_1`、`call_2` 等，映射同时用于历史调用和回执，原 ID 与 hash 保留于审计 sidecar。编号不从参数推测，也不按返回顺序分配；消息实际顺序保持。重复/未知 ID、缺失或跨轮回执仍拒绝，不能通过添加 ID 掩盖损坏轨迹。

当前 assistant 目标继续只生成工具名和参数，不监督随机供应商 ID 或由运行时分配的编号。解码器严格解析后，由本地适配层分配编号；回执用该编号接回历史。`prepare_history/prepare_prompt` 供训练编码和推理输入共同使用。只验证解析与历史追加，不执行无人机工具；尚未接入真实学生生成服务。

## Verified Results — 预定检查而非既成结论

本轮固定复用 v1 的 61 条合格 development 转换样本及全部 98 条 wire 请求。61 条验证完整目标/label；98 条只验证 prompt，尤其原先拒绝的 10 条旧搜索请求，不为失败/partial 回合新增正向标签。原转换分母和 Teacher 数不变。

预定验收：

1. 98 条请求全部保留审计记录，原 10 条要明确计为解决或仍拒绝；按 ID 重建的调用/回执语义与原 wire 一致。
2. 61 条完整样本逐 token 证明输入/目标边界，原当前目标语义和监督 token 保持一致；历史、包装、编号和 padding 不参与 loss。
3. 合成同名并行与反序回执通过；缺失、重复、未知、跨轮及名称不匹配负例拒绝。合成结果不称为模型能力。
4. 生成文本解析→运行时编号→追加回执→下一次 prompt 的往返一致，重复准备不产生额外编号或嵌套包装；供应商 ID 改名不改变 canonical prompt。
5. 使用同一真实 tokenizer 比较 v1/v2 token；记录 4k/8k/16k/32k 总长度与 prompt 另外预留 2048 输出 token 的诊断。超长整条拒绝，不截断；2048 是诊断档位，不是最终采数或训练参数。
6. 模板、代码、依赖、来源和测试封存；独立复核语义对应、loss 和全分母，旧包及源 seal 不变。

## Working Hypotheses / Open Questions

显式关联能消除序列表示中的 ID 丢失，是否改善小模型的关联理解或任务成功率仍需后续真实模型/训练评价。自定义模板会引入与原训练格式的差异，须同时用于 SFT 和推理并独立比较基座表现；本地往返正确不能替代模型能力验证。输入增加的开销实测后再判断，不能预先宣称效率提升。

正式 Teacher 采集仍需新来源的初态/质量准入、v2 provider driver、预算及质量审核；该输入修复不将旧搜索失败转为训练成功示范。

## 参考依据

模板实现参照 [Transformers 4.57.3 自定义模板说明](https://huggingface.co/docs/transformers/v4.57.3/en/chat_templating_writing)；训练完整序列与推理 generation prompt 的区别、渲染后关闭重复特殊 token，依照[同版本 chat template 文档](https://huggingface.co/docs/transformers/v4.57.3/en/chat_templating)。具体 Qwen 原生模板以仓库已封存 tokenizer 文件为准。这里的 canonical ID 历史包装是本地新增协议，不是官方原生格式。
