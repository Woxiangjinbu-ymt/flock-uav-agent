# M1：任务指令与执行证据的最小状态层

2026-10-06，基于冻结的 B1 定向补救版本 `cb80fde8269a09795782a6ef046d04c381b3f3c9`，该父版本在研究路线中称 M0。M1 首版只增加状态表示与有界摘要；是否有任务成功率收益，等待 fast100 同期对照。

## 范围与接口

每次 `execute` 创建独立 `TaskProgressLedger`，记录原始用户指令、带位置的原文分句、显式实体名称绑定、实际工具回执和事实来源。历史事件保留原证据，当前位置等事实在后续可能改变它的动作发生后标为失效；并行读写不能确定先后时标为 `order_unknown`。新任务清空动作记录，只将原 session 黑板中已有的局部知识标作 inherited。

名称仅作精确绑定：已观测且唯一、歧义、未解析分别记录。首版自动识别 Drone 数字编号、指定类型 Target 数字编号等显式名称；不猜测代词、隐含责任或完整任务逻辑。分句只是原文引用，不能据此推导所有先后依赖。`requirement_status` 和 `mission_completion` 保持 `not_evaluated`。

工具执行交给原 handler，middleware 仅观察返回值。原模型循环、30 个工具、参数、调用结果、终止标记和评分协议保持不变。没有新增模型调用、规划器、重试或动作否决。观察器解析失败会记录错误并继续原执行；这类错误纳入离线和在线审计，不能把退回基线说成 M1 正常起效。

模式由构造参数 `task_progress_mode` 或环境变量 `UAV_TASK_PROGRESS_MODE` 指定，构造参数优先；默认 off，错误值在初始化时拒绝。

| 模式 | 行为 | 用途 |
|---|---|---|
| off | 不创建 ledger 或 middleware，不增加提示 | 恢复原 B1 行为 |
| shadow | 只记证据，原 model request 与工具结果透传 | 离线和集成等价性检查 |
| summary | 每轮模型请求临时追加不超过 4000 字符的摘要 | M1 首轮实验配置 |

摘要包含原文分句引用、请求实体绑定、近期工具证据和相关实体事实，按区分配长度，明确报告省略数量。它不写入 graph 对话历史，因此不会逐轮积累重复摘要。完整指令及原工具历史仍可供模型读取。空响应恢复若发生，沿用同一次任务的 ledger；下一次 `execute` 必须创建新 ledger。

## 必须保留的证据边界

- 单次动作成功不代表整题完成；一架机到达不代表指定团队完成。目标 `is_reached` 与 `reached_by` 是会话历史，不能独立证明当前任务或当前位置满足。
- 返回 error 不保证没有副作用，例如低电量可能先强制降落。潜在状态变化会使旧状态失效，随后真实观测才能更新。
- 导航部分执行保留实际回执；中间端点未到达不阻止后续工具执行。未知状态不触发全局执行门禁。
- 局部可见目标不是全局目标分母，名称查询 404 不证明目标不存在。
- 拍照成功只记录照片动作，不推断照片包含指定目标；nearby 也不能代替照片对象证据。
- 不读取隐藏检查、全局目标全集、离线失败标签或答案来初始化在线状态。

启用原工具链 JSON 记录时，终态文件追加 `task_progress` 快照及模式/是否激活字段。原始回执仍保存在既有工具链和 API 记录中。终态前被杀掉的任务可能缺 ledger 快照，应明确报告证据缺口；不能以缺日志推定没有发生动作。

## 验收与实验

离线验收覆盖固定回复下关闭/旁路模型输入一致、工具与异常严格一次透传、invoke/stream 两条执行路径、跨题隔离、有界摘要，以及来自 dev240 的十条真实指令语义反例。另对 B1 已保存工具链进行只读回放；无完整工具链的中断任务保留缺口。

阶段性能实验见 [fast100 研究协议](../../../experiments/m1-progress-v1/README_CN.md)：冻结 M0 与 M1 各跑 100 题，同模型、2 个 worker、500 秒动作窗口、相同场内顺序，各自新 attempt。主指标为原外部任务通过，报告 W/L、场景差异及时间/token。表示功能通过不等于成功率提高；结果不确定或明显退化时先分析 M1，不直接推进 M2。

后续 M2 在同一状态上增加一个证据支持的行动机制；M3 保持可选。M1 首版本身不作为独立、完整的论文创新结论。

实现使用本地已安装 LangChain 的 [middleware 接口](https://reference.langchain.com/python/langchain/agents/middleware)：工具回执经 `wrap_tool_call` 观察，模型请求经 `wrap_model_call` 临时附加摘要；没有为此升级依赖。
