## 首批交付

保留失败、未评分及未启动行；两场合计计划分母固定为 40。题次与训练样本数分开统计。
- 独立评分成功、归档完整、工具调用及回执能对上、存在与任务相符且可归因的行动时，审阅该轨迹的决策轮。题初已满足检查、单凭口头宣告成功、截断、重复无进展、服务失败和回执缺失均需标注。记录保留与剔除原因。
- 每个合格决策轮用原始请求摘要定位，学生输入止于该轮之前能看到的命令、工具、消息和执行反馈，训练目标包含该轮回答、动作和相应版本保留的思考文本。隐藏检查、私有状态与本轮之后的工具回执留在评估侧。先导出保留／去除教师思考的两套监督，均保留合格动作，仅目标 token 参与 loss。
- 按场和按折发布实际耗时、HTTP 派发数、有完整 usage 的请求数、命中／未命中输入、思考与全部输出 token、结算金额、独立得分、合格轨迹和可用轮数、事件分布。第一场结束后即可整理第一批合格样本。若采集协议与首遍相同、全程完整记录，合格试采场次可计入首遍。协议调整后的执行单独记账。[逐轮开发样例](../../results/deepseek-sft-dev-examples-20261109/REPORT_CN.md)
