# Qwen3.5-2B 在 Mac 上的第一条 SFT 格式样例

2026-11-08 用 Qwen3.5-2B 的真实文本分词器和官方聊天模板，在 Mac 上复算一条已见 DeepSeek 开发轨迹。下载了四个固定版本的配置和分词文件，未加载模型权重。样例只在内存中重建，归档保留证据摘要和 token 数，加入正式训练集的样本数为 0。[官方固定修订](https://huggingface.co/Qwen/Qwen3.5-2B/tree/15852e8c16360a2fea060d615a32b45270f8a8fc) · [文件哈希与软件版本](summary.json)

## 学生在这一轮学什么

样例取自 11 月 3 日悬停开发回合的第 2 轮。学生可见原任务、此前的 `list_drones` 调用及其已返回的结果。教师随后写下思考，调用 `get_weather` 和 `sense_nearby_entities`。原独立检查器判该回合 2/2 通过，评分只用于审计侧选样。教师记录的 178 个思考 token 采用教师的计数口径；下表为学生分词器对整段监督目标的计数。[开发轮证据](dev_example.json)

| 演练方式 | 作为输入、屏蔽损失的 token | 作为监督目标的 token | 当轮学到的输出 |
| --- | ---: | ---: | --- |
| 保留思考 | 11,979 | 252 | 教师思考、关闭思考标记、两次工具调用及回复结束标记 |
| 外部预先关思考 | 11,981 | 63 | 两次工具调用及回复结束标记 |
| 给同一前缀，示范立即结束思考 | 11,979 | 66 | 立即关闭思考，随后发出相同两次调用并结束回复 |

第三行与第一行的输入 ID 完全一致，适合检验“由学生自己决定是否思考”的数据格式。此开发轮含新信息事件 E5。表中不同写法用于对照格式，正式训练时应按该训练版本的规则选择对应目标。该例中，第三行若先拼全文再分词，开闭标记之间的换行会合并，得不到推理时相同的输入 ID。示例按实际推理前缀分词，单独编码待生成的后缀，并验证拼接后的 ID 可无损解码。计分从第一个后缀 token 开始，工具回执和提示全文均不计损失。[掩码与 ID 摘要](sample_mask.json)

## 多机工具回执

固定修订默认关闭思考，显式打开时，起始思考标记已经在提示词内。模板以函数名和参数标签渲染工具调用。它保留最近一次用户指令之后的历史思考，更早的思考在本次夹具中被剔除。实际转换训练数据时，需要按实验臂主动处理历史中的教师思考。[官方模板](https://huggingface.co/Qwen/Qwen3.5-2B/blob/15852e8c16360a2fea060d615a32b45270f8a8fc/chat_template.jinja) · [模板实测](summary.json)

另构造两架飞机查询电量的例子，工具名称相同，回执按相反顺序到达。当两份电量回执交换所属调用、正文和到达顺序相同时，官方模板给出的输入 ID 逐个相同。学生仅凭这种输入无法辨认哪架飞机报告了哪个电量。[探针与夹具](probe.py)

候选修正在历史回执正文旁加入公开的调用序号、函数名和调用参数。两份电量回执仍按原顺序到达，交换归属后产生不同的输入，更名供应商 ID 后产生相同的输入。重复或缺少回执时均拒绝构造。用于上面的真实开发轮时，提示从 11,979 增到 12,008 个 token，252 个目标 token 逐项相同。[候选表示的实测](summary.json) · [开发轮复核](sample_mask.json)

下一步在 Mac 验证**学生输出到工具执行**的方向。旧 Qwen3 解析器遇到新版函数标签会报 `generated_json`，开启思考的原生输出还会触发 `malformed_thinking`。正式适配需要识别输入中已给出的思考起始标记、从生成部分读取结束标记，解析完整调用组，再派发工具；截断或半组调用要有拒绝派发的证据。这里的两项报错均来自固定回复的解析夹具。[已有解析器](../../../scripts/thinking_events/student.py) · [复算结果](summary.json)

## 复算

从项目根目录执行。首条命令只在本地缓存缺文件时读取官方固定修订。缓存齐全后可去掉 `--fetch` 离线运行。

```sh
set -o pipefail
audit=docs/audit/qwen35-2b-input-20261108
py=training/.venv-input/bin/python
"$py" "$audit/probe.py" --fetch | diff - "$audit/summary.json"
"$py" "$audit/dev_example.py" | diff - "$audit/dev_example.json"
"$py" "$audit/sample_mask.py" | diff - "$audit/sample_mask.json"
```

本次没有更新权重、调用教师或运行 Linux。Qwen3.5-2B 的真实工具执行成功率、推理速度与思考开关收益待实测。旧 G1/G2 的主模型、对照和门槛仍依已批准的协议；两项 Linux 复验顺延至租用 GPU 主机时。
