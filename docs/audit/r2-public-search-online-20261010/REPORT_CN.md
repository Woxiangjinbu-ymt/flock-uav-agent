# R2 晚期公开反馈搜索：原场景序列同期在线配对

日期：2026-10-10。按[封存规则](PROTOCOL_CN.md)完成原 R2 与显式启用搜索的 R2 配对。两臂各跑三个原场景的原顺序前缀，均为 **52 道整题、220 个原检查点、每题 500 秒、零重试**，并通过独立封存校验。搜索臂 **43/52** 道整题通过，对照臂 **37/52**；但这 **+6** 不能全部归因于搜索：六道同题型任务中只有一道实际触发，另两道新增通过继承了它留下的场景进度，其他题也有模型运行波动。

## 完整序列成绩

| 指标 | R2 对照 | R2＋搜索 | 配对差值 |
| --- | ---: | ---: | ---: |
| 整题通过 | 37/52（71.15%） | 43/52（82.69%） | +6 题、+11.54 个百分点 |
| 检查点通过 | 201/220（91.36%） | 205/220（93.18%） | +4 个、+1.82 个百分点 |
| Agent 到 500 秒截止 | 7 | 3 | −4 |
| 全臂墙钟 | 5,540 秒（92 分 20 秒） | 4,122 秒（68 分 42 秒） | −1,418 秒 |
| 任务结果汇总 token | 46,514,926 | 40,659,950 | −5,854,976（−12.59%） |

两臂的原检查均完整评分，无缺失任务；对照臂有一题虽到 500 秒，截止检查仍通过。按任务 ID 的结果转移为：**35 题都通过、7 题都失败、8 题仅搜索臂通过、2 题仅对照臂通过**。其中六道同题型任务贡献了三题“失败→通过”、零题“通过→失败”；其余 46 题有五题仅搜索臂通过、两题仅对照臂通过，净增三题。非候选题没有搜索触发，故它们的净差提示模型随机性、两次运行时变状态及场景承接的影响，不能当作搜索的直接收益。

逐请求供应商审计 token 与任务结果汇总 token 口径不同；两种原始计数均保存在[配对数据](paired.json)中，未混算。

## 六道总进度题的公开证据

| 任务 | 对照臂原检查 | 搜索臂原检查 | 搜索臂公开进度与触发 |
| --- | --- | --- | --- |
| `9c0b52a0` | 通过 | 通过 | 100%；未触发 |
| `7eba7390` | 通过 | 通过 | 100%；未触发 |
| `b1ad4f3e` | 截止时通过，Agent 超时 | 约 289 秒通过 | 90→95→100%；未触发 |
| `5e743d21` | 截止失败，末次公开进度 75% | 通过 | **434.179 秒、88% 触发；搜索后 96%** |
| `24ac1838` | 截止失败，末次公开进度 84% | 通过 | 进题后读到 96%；未再次触发 |
| `7cdefb56` | 失败，末次公开进度 85% | 通过 | 读到 96%；未再次触发 |

唯一实际触发发生在处理臂 `5e743d21` 的已完成 `get_mission_progress` 回执之后，原 500 秒窗口还剩 **65.821 秒**。确定性搜索从公开状态执行 **240 次移动尝试**（236 次成功、4 次受阻），读取 240 次无人机状态和附近实体、25 次公开总进度，新增 7 个公开感知障碍；在 **4.507 秒**内读到严格高于 95% 的 **96%**。随后主 agent 到达模型步数上限（`step_limit`），但在 500 秒前停止，原检查通过。此处的 96% 来自 `/sessions/current`，并非检查器或完整场景真值；原检查只在题结束后执行。

同一场景后续的 `24ac1838`、`7cdefb56` 进题时已经能读到 96%，两题均未运行搜索且原检查通过。这支持“前一题的公开反馈搜索改变场景状态，后题继承进度”的故事线，不能写成三次独立技能成功。三道旧成功题都保持通过且没有搜索运行，覆盖了本轮最直接的误触发回归检查。

## 可复核性与解释边界

[冻结元数据](../../../experiments/m1r2-public-search-prefix-v2/frozen/study.json)固定原 R2 提交 `69dd34c067ec97b746db5180684594c546a35172`、两臂源码与依赖哈希、原场景文件、模型配置和检查规则。处理臂与对照臂的封存源码差异只有 `uav_agent.py` 显式模式接线和三个搜索模块。对照与处理的[原始运行档案](../../../experiments/m1r2-public-search-prefix-v2/runs.json)均标记 `completed_and_verified`；[分析脚本](../../../experiments/analysis/summarize_public_search_online.py)按任务窗口匹配同名题轨迹，并强制要求两臂 52/220 完整分母。初次 `v1` 因沙箱拒绝本机端口在 0/52 评分前中止，未纳入成绩。

搜索只读取原 agent 的公开障碍黑板和公开无人机、移动、附近实体、会话总进度 API；触发函数只接收题面、已完成公开进度回执及本题已用墙钟。它默认关闭，处理臂通过 `UAV_TASK_PROGRESS_MODE=evidence_r2_search` 显式启用。工作区 agent 也已同步该接线；在线成绩始终来自预先冻结的处理臂，不来自后来同步的工作区文件。离线预检通过原 R2 相关测试；工作区同步后相关测试 **36/36 通过**，且默认关闭与显式接线冒烟检查通过。

**论文表述上限：**这是一轮同一开发集上的探索性在线机制与回归验证。触发门槛是在查看历史六题时间线后选择的，两臂又是顺序执行的独立模型运行；`5e743d21` 触发前两臂状态并不相同（对照末次 75%，处理触发时 88%）。因此可以报告公开回执触发、真实 API 搜索和后续检查通过的连续证据，不能给出独立泛化率、显著性或把整题 +6、墙钟缩短全部宣称为搜索的因果效应。下一轮应冻结门槛后在未参与开发的场景或重复配对上检验误触发、直接触发覆盖和整题净收益。
