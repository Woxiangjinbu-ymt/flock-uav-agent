# R2 公开反馈搜索：晚期触发探索与分叉回放规则

日期：2026-10-09。承接[短技能本地限时验证](../r2-timed-public-search-20261009/REPORT_CN.md)。**触发时间门槛是在看过这六道开发题的时间线后选出的探索性候选，不是事前盲定或独立验证。**本文件固定本轮可复算的条件，并作为未来在线配对前待冻结的版本。

## 只看公开回执的启动门槛

技能默认关闭；只有主 agent 显式启用时，才在一条已完成的公开 `get_mission_progress` 回执处评估[纯函数门槛](../../../agent4drone/coordinated_search_trigger_r2.py)。题面需同时包含 `all targets` 和 `session task progress exceeds 95%`，当前公开进度需 `<=95%`，原 500 秒窗口已经过 `>=400` 秒且还剩 `>=30` 秒。原进度检查器、完整场景、原任务结果、任务 ID 均不是触发输入。门槛不主动增加定时轮询；如果最后 100 秒没有可用公开进度回执，就不会触发。

在 R2 fast100 的 100 道题前公开题面中，该题面条件仅覆盖六道：三道原 R2 检查通过、三道未通过。按原工具轨迹把每条公开进度事件与对应 `/sessions/current` API 完成时间对齐，计算首个触发时刻。原检查结果只在触发时刻固定后用于分组。[shadow 复算脚本](../../../experiments/analysis/audit_public_search_trigger.py)保存逐次查询与 300/350/400/450 秒门槛敏感性。

## 原轨迹晚期分叉

只对被触发的三道开发失败题，在各自原题前快照恢复隔离服务端。按原 API 顺序重放截至触发回执的公开调用，要求没有跨越分叉边界的并发调用；逐项核对 HTTP 状态、命令结果与非电量文本、公开无人机位置、附近目标及障碍 ID，以及触发时总进度。电量消息差异单列统计，不当作精确一致。若任何核对失败，停止该题分叉，不用近似状态给策略打分。

核对后才用当前公开机群状态、R2 首次公开全机感知的历史障碍黑板和后续真实公开反馈，运行上一轮的确定性协调搜索。技能墙钟上限为触发时原窗口的剩余秒数；每次动作前查限，搜索每 10 次尝试查询一次公开进度，到 `>95%` 即停，任务原检查仅在搜索停止后调用。[分叉脚本](../../../experiments/analysis/pilot_public_search_trigger_branch.py)分别支持进程内 TestClient 与本机独立进程 HTTP。

此分叉把原 R2 前缀与新技能接续，是**历史轨迹的反事实机制试验**。它不包含原 agent 对新回执的模型反应，不保留真实并发调度时延，也没有在同一场景任务序列中形成新的在线成绩。三题不是独立抽样，且都参与门槛和策略开发；不得把分叉检查通过率写成方法成功率估计。
