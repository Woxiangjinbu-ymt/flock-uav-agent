# 模型调用必要性与决策失效审计口径

本次是历史开发轨迹的探索性审计，规则在查看案例后制定，不是预注册验证。主集为已封存 R2 fast100 的全部 100 题；补充集为公开搜索试验 control/search 各 52 题。重复题和同场景继承状态分别报告，不将 204 次执行当成 204 个独立任务。

## 审计单位与时间边界

- HTTP 请求、middleware 决策请求、工具调用、底层 API 请求分别计数。利用 middleware 索引关联 HTTP 请求，重试不新增决策边界。
- 请求只保存消息哈希，没有完整请求正文、可靠的逐请求起止时间或持久化待执行计划。因此不能恢复隐式思维，也不能直接计算可节约推理时间或保证调用发生在 500 秒评分窗口内。
- 只在同 segment、前缀不变、初始为 system/user 两消息时，以相邻请求消息数差减 1 恢复中间工具回执数量。按事件 start_sequence 分组，检查组间没有在途交叠；用完整 tool_chain 的工具顺序以及 evidence injection 的 tool_call_id 锚点交叉验证。组内不强行推断并发动作的先后效果。
- 确定性 worker 的 `coordinated-search-*` 事件独立统计，不伪装成模型 ToolMessage。最后一次请求后的未消费事件保留为尾部事件，不强塞到之前的模型输入。
- 不能对齐时中止生成并报告无法判定，不把错误边界纳入正常统计；本轮全部轨迹通过对齐检查。不使用最终成功、隐藏检查、未来动作或未来回执作为分类输入。任务分数仅在分类完成后附加。

## 分类与可主张范围

| 标记 | 当前公开前缀满足的条件 | 可以据此做什么 |
|---|---|---|
| INITIAL_PLAN | 首次请求 | 保留初始任务解释与计划，不计为可省调用 |
| REASSESS | 受阻、部分执行、资源不足、工具语义不支持或其他明确错误 | 相关动作的原执行假设失效；先判断技能是否可有界修复，超出能力才交模型；不代表整队都要停 |
| OBSERVE_OR_REPAIR | 参数包装错误、实际效果未知或公开状态冲突 | 已知未执行的序列化错误可修复；效果未知先查证；不能直接重放有副作用动作 |
| CONTINUE_CANDIDATE | 完整匹配三类简单指令语法之一，actor 已公开绑定，已有指定动作的成功回执，顺序没有偏离，明确还有后续步骤 | 有限技能可继续的候选；不是经反事实证明可删的模型调用 |
| CONFIRM_CANDIDATE | 上述完整语法的动作回执已齐全 | 可以转到公开状态核对；不宣告整题通过，不将最终回答调用算作节约 |
| UNDETERMINED | 其余情况，包括正常回执但无持久化下一步计划 | 保留未知；“没报错”不足以判为可跳过模型 |

简单语法仅覆盖：指定 UAV 起飞—转向—悬停，起飞—爬升—悬停，起飞—原地悬停。使用整串匹配，不以部分解析覆盖额外约束。这只是保守定位确定性序列机会的审计探针，不是拟议 harness 的完整任务编译器。

失效类别另记每个事件：blocked、partial、resource、unsupported、argument_schema、argument_missing、arrival_unverified、state_conflict、lookup_error、unknown_effect、other_error。移动路径完成但到达未核实归入局部核对；参数完全缺失不能当成只需重新序列化。重复受阻签名仅表示同 actor、同工具与参数且中间没有记录到该 actor 成功移动；不声称世界或所有前置状态相同。新实体、进度变化单独记录，实体“新”只指首次在当前任务的已消费回执中出现，不代表全场景首次发现。不能仅凭“有新信息”触发全局重规划。

## 审计与验证的分界

离线统计回答“哪里值得将执行与模型调度解耦”，不回答“删掉这些调用以后仍会成功”。确认需使用相同模型、公共信息、技能、任务序列与预算的在线对照。所有终止、未知、无计划和未触发样本保留在分母内。fast100 及这 52 题都已用于开发，不作为独立泛化集。
