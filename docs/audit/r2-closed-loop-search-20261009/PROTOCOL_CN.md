# R2 总进度题：公开反馈闭环搜索离线协议

日期：2026-10-09。以下主臂规则在本次首次成功闭环评估前写入；末尾的消融说明是在看到主臂结果后追加，不能视为同一时间的预注册。三个任务、软搜索范围、70 米候选格点、25 米覆盖评分格点、50 米感知半径、1 米公开障碍安全缓冲、每机最多 16 次行动机会，均沿用[已冻结的开环方案](../r2-public-aggregate-search-plan-20261009/REPORT_CN.md)。这是已反复分析的开发案例，不能当作独立测试。

## 唯一变化

开环方案为每架无人机事先排好最多 16 个端点；首次受阻后，该机的余下端点全部放弃。本轮改为每轮按无人机 ID 排序，依据**截至该轮实际公开可见**的机群位置、已完成感知端点与障碍形状，重选一个尚有覆盖增益且公开已知直线路径畅通的格点。每机每轮最多尝试一次，最多 16 轮。成功后记录实际终点感知；失败后保持原位，禁止同机从同一位置重复请求同一端点，并从当前位置做一次附近感知。新感知到的障碍形状可由后续所有无人机共享。若没有可选端点，本轮弃权，不读隐藏真值补点。

端点评分仍为 `新增公开覆盖格点数 / (1 + 直线距离 / 250 米)`。成功端点全局不重复；失败端点可由其他无人机从不同起点尝试。候选只由首次公开机群位置构造，不根据目标真值改动范围或格点。搜索本身不读取隐藏目标 ID、坐标或原检查结果；新发现目标只来自模拟的成功端点附近感知回执。未达到阈值也不追加轮次。

## 评估口径

使用与 R2 冻结版本逐字节一致的服务端障碍、耗电与目标几何规则，从三题各自原题前快照**独立**回放。场景真值只由模拟器判定起飞、直线移动、路径到达、端点感知和障碍附近感知；策略只收到成功/受阻、实际位置、电量以及当前 50 米半径内的公开实体回执。若远处障碍阻断直线、但当前位置感知不到它，策略只知道该次路线受阻，不获得该障碍形状。所有新增公开障碍须保存首次观察的动作及位置来源。

在 4、8、16 轮报告：行动尝试、成功与受阻、公开新增障碍、初始未达目标的新定位与新到达、总进度、原检查 `>=95%` 与题面 `>95%` 两种阈值、总直线距离及最低电量。与既有开环回放逐题并列，但两者均不是原服务端在线运行。失败动作仍消耗一次行动机会；每次受阻后的感知、规划计算与可能的模型等待均**不计入 500 秒**，故即使离线达到阈值也不能称作原 benchmark 成功。

## 入场判断

若三题在相同行动机会预算下均不能达到题面严格阈值，或需要大量受阻与额外感知，则不把这版策略直接接入 R2。若有跨题机会，先在隔离服务端副本用真实公开工具执行同一策略，记录调用墙钟和回执，再决定是否进行同模型、同 500 秒、同场景任务序列的在线配对。不得根据本轮真值回改策略后沿用同一评估标签。

补充诊断（看到主臂首次离线结果后提出）：保持相同回执驱动的重新选点和失败边记忆，但**不吸收新障碍形状**。这一消融用于区分动态选点与障碍几何学习的作用，不是主臂事前固定的独立验证，也不用于从多种策略中择优报告。
