# FlockCue 项目概览：进度与目标

更新于 2026-11-11。详细状态见[研究状态](RESEARCH_STATUS_CN.md)，阶段与门槛见[研究路线](RESEARCH_ROADMAP_CN.md)。

## 项目是什么

FlockCue 是一个面向多无人机协作的执行反馈 Agent Harness。主 Agent 在给定的工具、权限和预算内负责规划、分配飞机、执行和重规划。Harness 记录各机的任务状态和工具回执，支持有范围的失败反馈复用与恢复。仿真平台、原基准和部分 Agent 组件复用自上游工作，来源在[项目指南](PROJECT_GUIDE_CN.md)中列出。

**当前目标**是在原 1,500 题实验设置下实测 FlockCue + DeepSeek 的 600 题整题成功率，据此决定模块取舍。Harness 定型后，核验真实 DeepSeek 教师轨迹，依次训练约 2B 的 SFT、RL 学生并测量同设置下的 pass rate。[本批规格](specs/05-deepseek-harness-ab600/spec.md)

以下事件分类与假设来自暂缓的选择性思考研究，供后续实验参考。

| 事件 | 含义 |
| --- | --- |
| E1 受阻 / E2 效果未知 / E3 部分完成 / E4 明确失败 | 上一轮动作没有按预期生效 |
| E5 新信息 | 首次观测到新实体、障碍或进度变化 |
| E6 义务变化 | 任务点名的某架飞机完成条款或原路径受阻 |
| E0 无事件 | 上一轮回执齐全且均成功，本轮不思考 |

对照组包括教师自选、RACE 的 LoGiC、固定间隔，以及“每轮思考”和“从不思考”两个端点。主指标是独立评分的任务成功率，同时报告推理 token、总 token 和 P50/P95 时延。

## 待检验假设

在成功率相同的前提下，用执行事件监督思考比其他标签消耗更少的推理 token，而且机队越大优势越明显。若各标签效果相当，结论改为“执行状态信号已经隐含在教师行为或似然信号中”。这一假设目前尚无实验结果。

## 主要风险

以下为原思考方案的研究风险。

- G2 若显示开、关思考没有差距，“何时思考”就没有可优化的空间，主线需要重新评估。
- 自然条件下 E2（效果未知）和 E3（部分完成）样本很少，现有的 6 个 E2 全部来自故障注入。
- 600 题有历史开发暴露，结果只能称为“已知基准上的整场留出”，不能称为新场景泛化。
- RACE 只做 SFT 时推理 token 降幅为 4.3%–20.0%，本项目只做 SFT 的降幅可能有限。
