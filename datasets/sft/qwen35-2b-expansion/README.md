[完整覆盖表](COVERAGE.md)列出重点任务、场景任务族、场景、原题型及五类决策。区域覆盖按原题名中的 `Coverage` 归类，进度百分比题单列在其原题型。目标扫掠指 `Fleet Target Sweep`，四、五机编队指 `Fleet Coordinated Takeoff and Formation` 对应机数。收录早期决策的题也计入题数。各题实际保留了哪一步，见[题级审阅](../../teacher/2026-11-15-expansion/audit.json)。

两道四机编队均通过 16/16 项独立检查，但逐机动作记录显示部分飞机将东向距离拆在北移前后，不符合先北后东、每段足距的题意，两题所有轮均排除。两道五机编队均有逐机先北后东的执行证据，纳入限定机体感知、位置核验、分配队形位置的决策。后段定向动作超出学生输入上限。区域覆盖包含单机执行、双机分区执行和三机分区派发。三机案例中的受阻机后来重定位补完，纠错轮含方位误读，未用作标签。

目标扫掠由 4 题 4 轮增至 7 题 8 轮。三机案例新增目标发现和逐机分配导航各 1 轮，两道四机案例各新增 1 轮限定机体的目标发现。四机按西、南、北飞足距离的后段均超出学生长度。新采的五机扫掠在 500 秒截止时只通过 12/20 项检查，本版保留父集原有的 1 轮五机扫掠示范。本版首次覆盖五机编队、三机区域覆盖和五目标 70% 进度任务。

## 重建

在仓库根目录运行以下命令，生成数据、索引、覆盖表和发布清单。构建器重新投影每条新增教师回复，核对原生解析、ID 与行哈希并校验来源角色。

```sh
workdir=$(mktemp -d)
posttraining/.venv/bin/python -m posttraining.sft.expansion --output "$workdir/release"
```

发布检查使用训练器的 CPU 数据读取入口逐行核对掩码、监督 token、来源索引、EOS 和长度。另以全部 token ID 与监督起点排查重复。此次工作仅构建数据集。
