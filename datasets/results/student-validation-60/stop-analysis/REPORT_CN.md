# 首轮 SFT 的 48 道预算终止题

2026-11-12，对 A 折内部验证中以 `token_budget` 停止的 48 道 SFT 题做离线复核。48 题的正式得分均为失败。其中 5 题的仿真终态整题达标，43 题未达标。逐项连接了模型实际收到的请求、真实回复、带调用 ID 的工具回执、学生服务端 token 账本和独立仿真评分。原评分保持不变。[原配对结果](../REPORT_CN.md) · [48 题逐题表](episodes.csv) · [逐轮复核数据](evidence.json.gz)

## 5 道已经得到仿真器通过回执的题

五题中，两道基础起飞题的原仿真检查是高度和离地。FlockCue 对“原地起飞并悬停”还要求起飞前位置、动作顺序与新鲜状态证据。另两道含悬停的复合题，模型收到的规则要求保留原任务义务并说明可验证范围。停止调用、如实报告已做事项、声称整题成功，是三个需要分别评估的行为。

## 重复调用究竟有多少

以同一题内的工具名和规范化后的实参作键，将每次调用与上一次同键调用比较。上次发生在较早轮次才计为跨轮重复。回执相同要求 JSON 规范化后相同，非 JSON 文本要求原文相同。并行批次内的重复单列。即使回执相同，时间要求和中间动作也可能使复查合理。

| 项目 | 5 道仿真达标 | 43 道终态未达标 | 全部 48 题 |
| --- | ---: | ---: | ---: |
| 实际执行工具调用 | 47 | 543 | 590 |
| 有跨轮同参重复的题 | 3 | 22 | 25 |
| 跨轮同参重复调用 | 8 | 69 | 77 |
| 其中回执也相同 | 7 | 57 | 64 |
| 同批次内重复调用 | 0 | 19 | 19 |
| 整轮只发跨轮重复查询 | 8 | 36 | 44 |

77 次跨轮重复中有 66 次查询、10 次物理动作和 1 次规划。44 个整轮只发重复查询，共消耗 679,820 token，占已记账总量 15.88%。这是这些轮的实际成本，能省下多少取决于具体任务。23 道题全程没有跨轮同参重复，仍然耗尽预算。另有明确可纠正的错误循环，例如障碍导航题 `1b153d1b` 收到 10 次缺少 `obstacle_id` 的错误，五机搜索题 `eb9625aa` 收到 11 次缺少 `target_id` 的错误。两者都需要先解析有效实体 ID 才能取得新信息。[逐题与各轮参数](episodes.csv) · [原始回执归档](../raw/raw-paired.tar.gz)

43 道终态未达标题中，23 道有新增成功物理命令，20 道没有。13 道既产生了成功物理命令又通过部分底层检查。更早结束无法补足缺失动作；这些题也要覆盖纠错、实体发现和有效执行。

## 每题 100,000 token 花在了哪里

48 题共生成了 308 轮有效回复，每轮都选择了工具。最后另有 48 次请求在采样前被拒，均未生成回复，也未计入题级预算。按冻结的 Qwen 模板重新编码全部 356 次请求，逐一核对输入 token ID 哈希。已计入题级预算的 4,280,033 token 中，**完整输入占 4,229,872（98.83%），新生成占 50,161（1.17%）**。完成一次正常推理的轮数中位数为 6.5，范围为 4–9。首轮输入中位数为 8,568；被拒请求的输入中位数为 19,304，此时余额中位数为 9,746。[学生计数实现](../../../../posttraining/inference/server.py) · [逐题成本](episodes.csv)

| 已接纳输入的组成 | token | 占已接纳输入 |
| --- | ---: | ---: |
| 工具定义及其模板 | 1,924,008 | 45.49% |
| 系统消息 | 675,492 | 15.97% |
| 题面、注入的用户消息和生成标记 | 83,905 | 1.98% |
| 历史工具回执 | 1,421,728 | 33.61% |
| 历史助手消息 | 124,739 | 2.95% |

历史助手消息和工具回执中，495,680 token 是第一次出现在已接纳输入，**1,050,787 token 已在此前请求提交过**，再次发送占全部已接纳输入的 **24.84%**。其中 969,219 token 来自旧工具回执。按回执类型归属，`sense_nearby_entities` 和 `list_drones` 合计占工具回执 token 的 79.82%。一次短状态查询会多开一轮；该轮又携带全部工具定义、系统消息及此前回执。上述“重复发历史”和“重复调用工具”可以发生在同一轮，成本不能相加。

服务端按题保存累计账本，实际发给模型的消息和工具中没有本题余额。最后 48 次请求里有 4 次连输入本身都超过 32,768；若按通常的 2,048 token 回复预留计算，共 6 次还会遇到上下文门限。这些都在 43 道终态未达标题中。[预算准入顺序](../../../../posttraining/inference/__init__.py)

## 首轮到底教了多少次收尾

在 386 条实际训练标签中，每条都监督了 EOS，但只有 **5 条**是“根据当前证据输出文字并停止工具调用”的教师末轮，其余 381 条都发了工具调用。这 5 条全在同一个巡逻场景，合计 2,114/129,010 个监督 token（1.64%）。5 条均是教师宣称完成，4 条含 `[TASK DONE]`。搜索、目标分配、明确说明未完成或请求澄清的末轮均为 0。原悬停完成规则对其中 2 条给出超出覆盖范围的结果，另外 3 条不适用该规则。训练目标取自教师原答，未纳入 Harness 对完成声明的后置改写。[训练样本索引](../../../sft/qwen35-2b-first-pass/index.jsonl) · [首轮样本构造](../../../../posttraining/sft/FIRST_TRAINING_CN.md)

在 A 折训练侧通过题级语义审阅的 157 条教师轨迹中，157 条都有正常文本末轮。92 个末轮超出单条长度策略。65 个可按原格式完整表示的末轮中，仅 5 个入训，另 60 个在逐轮提名时未被选中。再按学生当前的准入逻辑逐轮计入教师输入和回复，只有 **18 条**原教师路径能原样走到结束，其中 1 条末轮已入训、17 条此前未入训。这个离线计算衡量长度和额度可行性，不预测学生会沿用教师路径。

这 17 条覆盖巡逻 6、搜索 5、目标分配 6。逐题复审还要检查教师末文是否超出公开证据。例如 `a05a871a` 原路径共 62,857 token，基础悬停有据，教师末文另外断言“无碰撞风险”，已有审阅指出证据不足。因此这 17 条是复审候选，尚未变成新的训练标签。[17 个候选及原始工具链索引](teacher-candidates.csv) · [训练侧逐题审阅](../../../teacher/2026-11-11-fold-a/audit/episodes.jsonl)

## 第二轮 SFT 的取舍

1. **先改数据配比，固定模型、Harness 和预算。** 复审上述 17 条 A 折训练侧候选，优先保留同一条真实轨迹中“最后一个必要动作 → 回执或必要核验 → 简短终答”的连续样本，并按场景和任务族统计覆盖。对超长或含无依据断言的案例，用同一训练侧任务重新采集简短的真实教师路径，逐轮检验学生是否还付得起最后一次输入与回复。
2. **同时教继续、确认完成和如实结束。** 用真实回执构造对照。缺 ID 或收到拒绝时应修正参数；状态发生变化或仍有后续动作时应继续；必要事实已经核对时可直接结束；缺少不可补录的前置位置或可验证时长时，应报告已执行动作及未核实事项。预训练数据中的教师原文、公开工具回执、审阅理由分别保留，私有检查结果只进审计旁表。
3. **用配对实验判断改数据的贡献。** 建议从同一首轮检查点出发，在相同优化器步数、尽量匹配的监督 token 和任务族配比下，对比“继续训练原样本”与“加入收尾和纠错示范”。在冻结的 A 折 60 题上报告正式通过率、私有终态通过率、终态未过却宣称完成的题数，以及公开证据充分后继续调用的轮数。48 条诊断轨迹只用于分析，B 折 300 题继续独立保留。
4. **上下文改动单列实验。** 如果仍大量出现终答尚未解码就被拒，分别测试精简大块机队/感知回执、减少重复输入或预留一个可实际送入的终答请求。每次改变输入或预算规则后，用两组相同设置重测。给模型加预算提示同样属于推理侧改动。当前记录可算出成本，不能据此推算任何一种改法会新增通过几题。
