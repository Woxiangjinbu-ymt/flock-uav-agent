- **学生设置。** 数值依次为上下文 / 单轮生成 / 单题累计 token 上限。基座与各检查点按完整分母报告；原预算五个续训检查点沿用同一基座历史对照，三个放宽预算的配置各自重新运行基座。教师与学生的推理预算不同。训练与选模排除 B 折。[SFT 设置与选模规则](sft/README.md)
- **计分。** 每场 20 题原序执行，单题动作窗口 500 秒。正式整题通过要求原检查树达标，终止性模型服务错误计败。单看仿真终态、叶检查、训练 loss 和探针 loss 的结果见 SFT 主表。
