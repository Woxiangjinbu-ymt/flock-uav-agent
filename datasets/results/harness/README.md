# Harness 实验主表

在冻结的 600 题上，原版 Agent4Drone 和 FlockCue 使用同一模型名 `deepseek-flash`，正式整题通过数分别为 **506/600** 和 **544/600**，净增 **38 题（+6.33 个百分点）**。其中目标分配贡献 27 题，区域分配与巡逻贡献 9 题，区域搜索贡献 2 题。

## 实验设置

- **题集。** 原始基准含 75 个完整场景、1,500 题。核心基准从 3 个任务族 × 5 档难度的每个组合取 2 场，共 30 场、600 题；A 折内部验证的 3 场包含在其中。另有基准外 3 场用于教师示范扩充，在表中单独标明。各范围不相加。[场景角色](../../original-benchmark/scene-roles.csv)
- **模型与系统。** 原版 Agent4Drone 分别以 `qwen3.8-flash`、`deepseek-flash` 各跑一次 1,500 题。FlockCue 使用 `deepseek-flash` 实跑一次完整 600 题。下表按模型 ID 汇总，原始部署记录保留各次运行的环境与服务元数据。[两模型全量发布表](../benchmark-1500/published-tasks.csv.gz) · [FlockCue 运行摘要](../benchmark-600/summary.json)
- **统一 600 题对照。** 以场景 ID 和任务 ID 配对。原版 DeepSeek 的 10 个完整复测场景统一取复测结果（200 题），其余 20 场取全量首遍（400 题）。同一规则也用于表中 A 折子集。原版 Qwen 直接取全量首遍的对应题位。FlockCue 的 600 个结果全部来自同一次运行，每题只计一次。两部分分别贡献 168/200 和 338/400。[统一逐题表与来源列](core-600.csv)
- **运行与评分。** 核心系统实验使用 8 个场景 worker、客户端温度 0.1、每题 500 秒动作窗口。每场按原始顺序连续执行 20 题，场景内保留状态和黑板。以冻结终态的原检查树判整题，终止性模型错误及未获评分的题按失败计入完整分母。各系统按自己的动作推进场景。[执行协议](../../../runtime/README.md)

## 系统与模型对照

单元格为正式通过题数 / 全部题数（通过率）。末列比较使用 DeepSeek 的两套系统，分别给出净增题数与百分点差。各题集的所有可用系统组合及其逐题得失见[完整对照 CSV](comparisons.csv)。

| 题集 | 原版 + Qwen | 原版 + DeepSeek | FlockCue + DeepSeek | Harness 净增题数 / 百分点 |
| --- | ---: | ---: | ---: | ---: |
| 全量基准 | 1,151/1,500（76.73%） | 1,243/1,500（82.87%） | — | — |
| 核心基准 | 467/600（77.83%） | 506/600（84.33%） | 544/600（90.67%） | +38 / +6.33 |
| A 折内部验证 | 45/60（75.00%） | 47/60（78.33%） | 56/60（93.33%） | +9 / +15.00 |
| 基准外教师扩充 | 41/60（68.33%） | 47/60（78.33%） | 51/60（85.00%） | +4 / +6.67 |

全量 1,500 题在同一原版系统下更换模型，DeepSeek 比 Qwen 多通过 **92 题（+6.13 个百分点）**。在核心 600 题上，原版 DeepSeek 比原版 Qwen 多通过 39 题；FlockCue + DeepSeek 比原版 Qwen 多通过 77 题，这项差值（+12.83 个百分点）同时包含模型与 Harness 两个变化。
