## 执行与核对

每一轮都先按旧策略选择历史，上限为 32,768 总 token，预留 2,048 输出。只有最短必要输入仍超过 30,720 时，才以 47,104 输入上限尝试容纳系统说明、题面、工具定义及最新一组完整的调用和回执。下一轮重新从普通窗口开始。对上一轮实际发生的 19 个拒绝点做静态回放时，18 个能送入，包括预先登记的全部 11 个目标题拒绝点。正式首遍允许教师自由执行，产生的新请求会改变后续所需输入长度。

本轮 975 个实际发出的逻辑请求中有 92 轮启用 48K，最大实发输入为 46,882 个 Qwen token。12/60 题仍产生了本地限长拒绝，3/60 题发生动作窗口超时。本轮墙钟 63 分 55 秒，上一轮为 21 分 33 秒。采集提交为 `83ccebe3`，git 分支为 `codex/teacher-collection-v2-pilot`。原始现场和逐轮索引保存在仓库旁的 `MultiUAV-Plat-runs/teacher-collection-v2/fallback-48k/`。逐题表同时保留正式通过、初态、扩窗、拒绝、连续可重放轮数和仅考虑累计预算的轮数。[预登记](registration.json) · [比较程序](../../../../posttraining/trajectories/compare_windows.py)
