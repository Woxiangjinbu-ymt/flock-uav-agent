## 哪些回执撑满了输入窗口

753 个逻辑轮中，734 轮收到完整教师回答。按固定 Qwen 模板计数，发出请求的逻辑轮中 367 轮缩短了可见历史，输入最大 30,719 token。其余 19 轮在发出之前被拒绝。此时系统说明、题面、工具定义和最近一组完整调用及回执合计已经超过 30,720 token，再删除更早历史也无法送入。19 组中，按字符计最长的单项回执分别来自 `sense_nearby_entities` 11 次、`move_along_path_and_sense` 5 次、`navigate_to_and_sense` 2 次、`move_towards_and_sense` 1 次。每组最长回执为 12,645 至 62,610 字符。字符数仅用于定位回执，限长判定使用 Qwen token。

735 次 HTTP 尝试均收到 200 响应头。其中一次响应体读取中断，随后重试成功。该题 `6aabb8de` 正式通过，原始档案按不完整处理。另有 `253205de` 在最后一次本地拒绝前已达到仿真通过条件。两题都计入正式通过数，其轨迹均排除于两组训练行。

### 重建与预算

从同一份 L1 和同一份审阅清单独立构建两次，两组训练文件、索引及清单共 7 个文件逐字节一致。实发 Qwen 前缀与训练投影已核对，1,026 项工具调用全部关联回执。两组均通过现有训练加载器的行哈希、全 prompt 掩码、目标及计数检查。只允许来自登记的三个训练场景和相应原题 ID。训练行只含 `input_ids` 和 `labels`。完整数据及审阅清单保存在本地试采目录，汇总清单 SHA-256 为 `4b7d9f29695d4bea1f8ff5427c00c8f959e72c59c7c0055ae77ef676b5a3cacf`。

## 下一版验证顺序

1. 在 19 个已封存的拒绝位置重放。先处理感知结果和复合移动回执中的大段重复实体列表。保留调用 ID、对象、执行状态、失败或部分成功、位置及题目有关的证据，完整原件留在 L0。记录各处精简前后的 Qwen 长度并核对证据归属。
2. 同时重放已通过任务的后段核验轮，验证公开回执精简后仍能支持原有决策，核对输入前缀、动作与结果。分别统计单轮长度和题级累计预算。
3. 冻结下一版策略后，按同一三场、题序、评分和门槛重新首遍试采。只有整题通过数和长题后段示范同时达到门槛，再决定是否放量到 1,020 道训练题。
