# 完整 100 题初态与前 20 对成本校准执行协议

授权日期为 2026-10-16。已授权准备全部 100 题及离线回归，在线范围严格为建议队列中 `cost_calibration_block=true` 的前 20 对、40 次。其余 360 次尚未授权；校准结束必须暂停，不能自动续跑、重试或补跑。

本协议沿用 [完整对照方案](./experiments/minimal-harness-full100-plan/PROPOSAL_CN.md)。模型 deepseek-flash、temperature 0.1；两臂使用相同冻结 v2 基础运行时中的 agent、提示、原工具、技能与强制守卫，仅调度策略为 applicability / failure。新适配层不预提交技能、不预灌黑板感知、不提供预提交提示，不给在线任务注入故障。模型从原指令自主观察、start、resume、cancel 或使用原工具。

## 初态与评分

100 题均从各自原场景完整对象图恢复；没有前置降落、充电或访问目标脚本。原位置、电量、障碍、任务文字及检查树保持不变，源文件元数据保留，任务相对时钟与控制器运行计时器采用共同纪元。五个场景当前没有移动目标；天气使用按场景固定种子的 501 秒事件表。每个任务保存完整快照与 SHA，并校验结构哈希及公开初态哈希；同题四次状态相同。

准备阶段完成 400 次恢复、私有历史/电量/RNG 污染清除以及 605 个原 checker 叶子的恢复前后复核。100 题均没有初始整体通过。指令中的“再次起飞”“继续覆盖”等均是本任务内部步骤，不依赖前一题，因此不添加共同前置动作。任务级义务以原指令、原检查树和实际历史联合审计，不以模型声明为准。

计时在恢复及纯准备校验后、构造 agent 的首次公开观察之前启动，包括初始观察、模型选择技能和后续执行。隐藏评分只在不可变快照上运行原服务器 checker，任务事件过滤起点为共同纪元；不将 checker 或任务标签反馈模型。

## 截止时刻和动作事务

任务时间窗 500 秒，工具步骤 600，图循环 1800，每计划 API 2000，局部修复 16，搜索轮数 16。SDK 与空输出自动重试均为 0。本地执行进程看门狗 630 秒。

任务提前结束或到达 500 秒时，立即关闭准入并保存不可变评分快照。在途模型可排空以保留真实 HTTP 与 usage；不得再执行动作、再调用模型或改变已封存评分。

模拟器单个公开命令采用原子事务提交：请求完整返回且未越过截止时刻才提交其效果；未及时完成的命令保留尝试、原回执和候选事件，但将其未提交状态恢复，不计入评分和已执行路径。多 waypoint 的 `partial_success` 在截止前完成时，其实际完成段全部计入，不把未走段计入。此语义只适用于本进程内离散模拟器，不声称真实无人机动作能够回滚；不是 v1 的截止后排空评分语义。离线测试明确覆盖跨界命令及迟到模型响应不能改变评分的情况。

## 动作与路径日志

记录每次公开 API 的起止时刻、端点、参数、实际回执、是否提交、task/preparation/scoring 阶段、模型工具 ID、skill/raw 来源与 plan_id。控制器历史事件在原 500 条裁剪之前追加到独立日志，不改变原历史上限。按唯一事件 ID 汇总实际段长 Lxy、Lxyz、累计垂直位移；不从终点直线距离或回执成功数推断路程。

逐动作记录 battery_volume 前后变化，消耗和充电分列；不把净剩余电量当作总消耗。五场景原距离模式均为二维，主路径指标采用 Lxy，另报 Lxyz 和垂直位移。这是离散模拟器代价，不是实测飞行能耗。原始控制器后台循环本来只推进移动目标、会话同步和天气，本适配层不额外引入原协议未调用的无人机持续耗电循环。

start/resume/cancel 的返回、包装拒绝及异常均追加记录。同 plan_id 恢复、游标继续、相关外部动作使计划失效，以及 needs_replan 后的实际原工具接手分别审计；有动作或 completed 字样不代表完成剩余义务。

## 队列与停止

完整建议队列仍为 400 次。启动器只接受冻结 manifest 明列的 40 个 trial ID，且无 continue/resume 命令；直接执行器也拒绝未授权 ID。两个 worker 明确为 0/1，各运行前 10 个完整配对；同对按冻结先后相邻执行，每次都重新恢复初态。第 40 次封存后状态为 `calibration_complete_paused_pending_user_decision`，没有第二轮或剩余任务的自动分派分支。

成本校准前缀含 5 场景各 4 对、2 道简单链、1 道搜索与 17 道原工具任务。每条保留首轮结果；发生终止性模型/HTTP、基础设施、checker、哈希或封存错误立即停派，已有在途执行可结束并保留证据，不自动恢复。任务本身失败、无有效答复、循环或时间预算触顶如实计分，不改任务。本轮始终受 40 次执行硬范围限制。

校准结束核对 40 份封存、20 对初态、实际顺序与调用日志，报告 input/output/cache token、HTTP、模型调用、就绪时间、完整模型墙钟、动作数、部分路线和路径代价，以及模型选择/恢复/接手的实际暴露和证据质量。只作校准阶段描述，不外推完整 100 题成功率；再由用户决定是否继续其余 360 次。
