# 搜索与输入成本候选的本地合同验收

本批预先固定 7 条件 × 2 配置 = 14 槽。控制为 schema 2、full_v1、observed_target_v7；候选为 schema 3、compact_tools_v1、search_progress_v8。其余任务、初态、脚本、权限、执行状态合同、预算和评分器相同。输入 JSON 对象兼容不在本轮改动中。

条件为 c74d7020 短链技能、6c3f98ce 原工具导航、fdd21809 搜索技能退出、c74d7020 原工具/技能起飞回执丢失后状态查询及悬停，以及既有 partial 开发场景的恢复正例和省略恢复阴性。后两例复用冻结 study，不重新生成。manifest 哈希写入 plan.json。全部是已知 development 数据。旧搜索正例的独立防回归由专门验证另列，不合并成本批分母。

所有模型响应由公开脚本提供，通过真实 SDK、工具、ASGI 仿真和冻结 general_agent 入口执行。主体 ID 只由实际公开 list_drones 回执解析；partial 后续点只由原始请求、公开 partial 回执及状态解析。没有 provider、自然模型决策、Teacher 采数或训练。脚本中的 [TASK DONE] 仅结束执行，任务完成只由独立 scorer 判断；搜索明确预期未完成，不让脚本编造成功。

每个配置分别运行 main 5 槽和 partial 2 槽；四个子批先全部 prepare 冻结，再运行。每槽 fresh worker/scorer；外网禁止。已启动/未启动/失败全部保留，不能删失败槽提高成绩。冻结源在前后复核；已有输出不可覆盖或续跑。

通过条件包括：14 槽完整独立评分、初态成对一致、无网络尝试/私有泄漏/后台未排空；正常短链/导航的动作和评分保持；unknown 原始起飞真正成功提交且只执行一次，后续独立状态查询与 hover，ledger 仍为 unknown；partial 保留 A 已生效和 B 未完成事实，正例只规划 B，阴性维持 2/4。公开进度不是隐藏 checker。搜索允许动作/控制/回执不同，但不能降低已获得进度，候选只能有根据交回或按原严格 >95% 条件完成。

每次实际 wire 与原始 graph 消息逐条核对；只容许封存 ledger 中可定位的维护附注。完整工具回执、原始任务、tool call ID、参数及历史顺序必须保留，不静默裁切。报告实际 HTTP body 字节和工具 schema 的规范序列化字节/哈希，明确两者口径；不把模拟 usage 或字节当作真实 token。

减少静态提示或子程序动作不能证明模型成功率/token 收益；交回后自然模型可能继续高成本搜索。新停滞门控的最优性、泛化、provider 对提示变更的行为和端到端收益仍需另行授权的公平真实实验。正式运行后只读 --verify 复算封存哈希和全部验收，任何失败保留。
